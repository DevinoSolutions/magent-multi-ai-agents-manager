# Nodes Implementation Plan (master)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run a project's whole Claude Code session on a pool machine (`devino-second`…`fifth`) under tmux, with git as the source of truth, transcripts/state pulled home, the existing attach supervisor as the local window, and `@nick` in the status bar.

**Architecture:** Four new leaf modules (`nodes.py` pure policy, `remote_mux.py` the single ssh/tmux/git seam, `node_scripts/*.sh` shipped over stdin, `node_sync.py` the daemon) plus `cli/node_cmd.py`; the launch path gains one dispatch branch; `attach_client` gains `--mux tmux`; `cli/attach` lifts its wt spawn into a shared function. Spec: `docs/superpowers/specs/2026-09-24-nodes-design.md` (decisions D1–D12 are settled).

**Tech Stack:** Python 3.10+ stdlib (`subprocess`, `shlex`, `tarfile`, `json`), click, bash scripts on the node, tmux, git, gh, Windows OpenSSH client. No new Python dependencies.
