# Nodes Sub-plan K: the MCP relay (`mcp_relay.py`, `/relay/<name>/mcp` on `magent serve`, relayed provisioning)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A node's Claude Code can use a PC-bound MCP server, first of all `stealth-chrome-devtools-mcp`, the stealth browser that drives this PC's logged-in profiles.
- Plan F drops every stdio server and every loopback URL at provisioning, because neither works from a node (`nodes.mcp_skip_reason`).
- For each name in `settings.mcpRelay`, provisioning instead ships an `http` entry. It points at `/relay/<name>/mcp` on this PC's `magent serve` and carries a bearer token.
- `magent serve` checks the token and streams each request to the server's loopback HTTP backend.

**Architecture:**
- A new leaf, `src/magent/mcp_relay.py`, holds all the logic:
  - name rules and the per-name token file (`~/.magent/relay/<name>.token`, 0600, generated once);
  - the classification of a PC `mcpServers` entry into `stealthy`, `http`, or `unrelayable`;
  - the stealthy backend resolver, through stealthy's OWN ops CLI (`stealthy status`, and `stealthy ls --json` as the cold start);
  - `RelayState`, which is serve's one table of relays;
  - the streaming forwarder `proxy`, the request entry point `handle`, and `relayed_scope`, which is the provisioning seam;
  - `local_report` for `status` and `doctor`.
- `upload_server.py` only routes `GET`/`POST`/`DELETE` `/relay/*` to `mcp_relay.handle` and runs `_supervise_mcp_relay` on a daemon thread. That thread reloads the table every 30s.
- No Funnel code ships. A cloud session gets no relay in 3.20.0 (K10), so `tailnet.py` is unchanged.
- `remote_mux.py`, the only module that dials a node, gains `probe_relay`.
- `cli/doctor.py`, `cli/status.py` and `cli/node_cmd.py` render rows. They decide nothing.

**Tech Stack:** Python 3.10+ stdlib (`http.client`, `hmac`, `secrets`, `socket`), click. `curl` on the node. No new dependencies.

**Worktree for execution:** `<scratch>/wt-nodes-k`, branched from `feat/nodes` after PR-D and PR-F have merged. Per master §4, K runs in parallel with G after F, and I and J follow K. Task 0 probes both D and F. Every "Run" command runs from that worktree root. On a RAM-starved desktop, run the FULL gate (Task 14) on `box-fifth` per master §0.

**Decision record.** K1–K10 below were adopted as **DECISION-16** in master §3. Docs written by this plan (Task 14) cite DECISION-16, never a K-number.

2. **The wire, from the node (bash).** First define a helper that turns the provisioned entry into a curl config. The token then travels on curl's stdin (`-K -`) and never reaches argv, the screen or shell history.
   ```bash
   relay_cfg() {  # $1 = good | bad | none ; $2 = mcp | health
   python3 - "$1" "$2" <<'PY'
   import json, os, sys
   e = json.load(open(os.path.expanduser("~/.claude.json")))["mcpServers"]["stealth-chrome-devtools-mcp"]
   url = e["url"] if sys.argv[2] == "mcp" else e["url"].rsplit("/", 1)[0] + "/health"
   print('url = "%s"' % url)
   if sys.argv[1] != "none":
       auth = e["headers"]["Authorization"] if sys.argv[1] == "good" else "Bearer not-the-token"
       print('header = "Authorization: %s"' % auth)
   PY
   }
   INIT='{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-06-18","capabilities":{},"clientInfo":{"name":"k0","version":"0"}}}'
   H=(-H 'Content-Type: application/json' -H 'Accept: application/json, text/event-stream')
   ```
   a. **The token gate.**
      ```bash
      for t in good bad none; do relay_cfg $t health | curl -sS -o /dev/null -w "$t %{http_code}\n" -K -; done
      ```
      - **Expect:** `good 200`, `bad 401`, `none 401`.
      - **Proves:** the bearer gate works on the node's real route over Tailscale, and the backend resolves through `stealthy status`. A 200 means the backend is reachable.
   b. **Initialize (HTTP/1.0 tolerance).**
      ```bash
      relay_cfg good mcp | curl -sS -i -N -K - "${H[@]}" --data "$INIT"; echo "curl exit $?"
      ```
      - **Expect:**
        - the status line `HTTP/1.0 200 OK`;
        - an `mcp-session-id:` header;
        - a body carrying `"result"` with `"serverInfo"`, either as plain JSON or as an SSE `event: message` / `data: {...}` frame;
        - `curl exit 0` when the connection closes.
      - **Proves:** the POST path forwards end to end, and a close-delimited response (no Content-Length, no chunking) is read complete.
   c. **SSE liveness.**
      ```bash
      sid=$(relay_cfg good mcp | curl -sS -D - -o /dev/null -K - "${H[@]}" --data "$INIT" \
            | tr -d '\r' | awk -F': ' 'tolower($1)=="mcp-session-id"{print $2}'); echo "session: $sid"
      S=(-H "Mcp-Session-Id: $sid" -H 'Mcp-Protocol-Version: 2025-06-18')
      relay_cfg good mcp | curl -sS -o /dev/null -w 'initialized %{http_code}\n' -K - "${H[@]}" "${S[@]}" \
        --data '{"jsonrpc":"2.0","method":"notifications/initialized"}'
      relay_cfg good mcp | curl -sS -i -N --max-time 20 -K - -H 'Accept: text/event-stream' "${S[@]}"; echo "curl exit $?"
      relay_cfg good mcp | curl -sS -o /dev/null -w 'delete %{http_code}\n' -K - -X DELETE "${S[@]}"
      ```
      - **Expect:**
        - `initialized 202`;
        - the GET's `HTTP/1.0 200` and `content-type: text/event-stream` headers arrive at once;
        - the connection then stays open until curl stops it at 20s, ending with `curl exit 28`;
        - `delete 200`. A 405 only means the backend does not let clients end sessions, which is harmless.
      - **Proves:** the relay streams (`read1` plus a flush per chunk) instead of buffering until close. An early `curl exit 0/52/56` means the relay dropped the stream. A 405 on the GET means the backend has no standalone stream. Record it; it is not a relay failure.

   - **The 401 behaviour (B5's second fact).**

## CONFLICTS and assumptions (read before Task 1)

**K1. `settings.mcpRelay`, not `settings.nodes.mcpRelay`.** `settings.nodes` is B's `{nick: NodeConfig}` map. A key named `mcpRelay` there would be parsed as a nick and fail the 1-6 character nick rule (F6 flagged the same thing). K adds a sibling top-level settings key, `settings.mcpRelay: list[str]`. Its default is `["stealth-chrome-devtools-mcp"]`.

**K2. DECISION-12's "magent supervises `stealthy serve --http`" is wrong for this build and is not implemented.**
- Per V5, `serve --http` starts a second, unregistered backend that stealthy's own registry, reuse gate and orphan recovery know nothing about. On a fixed port it collides with a registered backend. On a free port it doubles the browser-holding processes on a RAM-starved PC.
- Per V2/V3, the stdio entry the PC already uses is a proxy onto a shared HTTP backend that ALREADY speaks streamable HTTP on loopback.
- The relay therefore fronts **that same singleton backend**. It discovers the backend with stealthy's own selection (`stealthy status`, V7). When the answer is `not running`, and only then, it asks stealthy's own cold start (`stealthy ls --json`, V8).
- magent never starts a backend any other way. It never kills, restarts or evicts one. A wedged backend is reported in stealthy's own words and left alone.

**K3. One token per relayed NAME, not per session.**
- DECISION-12 says "per-session bearer token". A token is baked into the node's `~/.claude.json`, and F's provisioning is digest-cached. A per-session token would change the `mcp` digest on every dispatch and re-provision every node on every launch.
- The token lives in `~/.magent/relay/<name>.token`, is generated once, and is reused.
- Rotation: delete the file, then run the next provision. `magent node setup`, or any dispatch whose digest changed, re-ships the new token. serve re-reads the file on a mismatch, so no restart is needed (Task 8 pins this).

**K4. A literal header, never `${VAR}`.** Per V10, env expansion in `~/.claude.json` is undocumented. The relayed entry carries `"Authorization": "Bearer <literal>"`. The node's `~/.claude.json` therefore holds a secret, which is why F's payload member is 0600 (V13) and why B1 below exists.

**K5. The node probe uses `curl -K -`, not `curl -sf -H "Authorization: …"`.** The master brief says "remote `curl -sf -H`". A `-H` argument would put the token in argv on a SHARED node, where any other Unix user can read it in `ps`. The law is "never in argv", the same as for the gh token. The probe instead feeds curl a config file on stdin through `remote_mux.run(..., input_bytes=...)`. It also reads the status code (`-w %{http_code}`) rather than using `-f`, so 401 and 502 are told apart.

**K6. The relay must NOT trust loopback.**
- Anything tailscaled proxies arrives at serve FROM `127.0.0.1`. That covers a `tailscale serve`, and a Funnel the user might set up on their own even though magent ships none (K10).
- Any other local process can also reach loopback.
- A "loopback is trusted" shortcut would therefore turn a proxied relay into an open, credential-equivalent browser. Every relay request is token-checked, whatever its source.

**K10. RULING (DECISION-12, cloud reach): the cloud relay is DEFERRED to the DESIGN.md known-debt ledger. magent ships no Funnel code in 3.20.0.**
- The only route from a cloud session to this PC is a public Funnel plus a Custom network allowlist that the user edits by hand (V16).
- That route would publish the credential-equivalent browser endpoint to the internet behind one bearer token, for a use nobody has asked for. The stated use is the user's nodes.
- magent CAN reach a cloud session's MCP config, via a claude.ai-synced plugin's `.mcp.json` (found by plan J). So the deferral does not rest on dead code. It rests on the security stack alone: a public Funnel, a long-lived bearer pasted into a cloud environment, and an unverified egress bet. The Task 14 ledger row names that plugin route for a revisit. No `cloud_entries` ships.
- What ships instead is ONE constant, `mcp_relay.CLOUD_UNREACHABLE`, which plan J prints for a `node: "cloud"` bring-up whenever `settings.mcpRelay` is non-empty (Task 11).
- A source pin keeps any `tailscale funnel` invocation out of `src/`.
- Revisit only when a cloud user asks. The work would then be: the Funnel on its ts.net name, the Custom-allowlist instruction, and a public base in `relayed_scope`. The token stays mandatory.

**K7. Provisioning goes through one function, and the relay classifies first.**
- **The call site.** The ONE caller of `nodes.user_scope(home)`, F's `remote_mux.provision_node` (DECISION-24), switches to `mcp_relay.node_user_scope(config.settings, home)`. Its callers are exactly two, `node setup` (`force=True`) and D's `launch._provision_once`, so one swap covers every provision. `node doctor` is read-only: it never calls `provision_node`, installs nothing and ships no token.
- **The pin.** A source pin in Task 10 fails the build while any direct caller remains. It REPLACES F's own source pin, `tests/unit/test_node_provision.py::TestProvisionNode::test_src_builds_a_user_scope_in_exactly_one_place`, in the same commit. This is the DECISION-17 seam handoff.
- **The order.** `node_user_scope` takes the relay's claimed names out BEFORE F's transport table runs, via `nodes.user_scope(home, relayed=...)`. A relayed name is then either relayed or skipped with a relay reason. It never falls through to F's "PC-local" or "not on the node", and it never triggers the node's `command -v` probe.

**K8. No token in any log line or any Sentry frame.** Per V14, a `log.exception` from a frame holding the Authorization header would hand that header to Sentry as a local variable.
- **Expected failures.** `handle` catches a proxied request's expected failures (`OSError`, `ValueError`, `http.client.HTTPException`) and logs the CLASS only.
- **Bugs.** Anything else propagates to serve's existing crash log, and no relay frame holds a token. The header lives only in `_refusal`, which cannot raise. `Route.token` is `repr=False`.
- **Supervisor.** The relay supervisor logs a failed refresh by class too (Task 9), because `ensure_token` runs inside `state.load`.
- **No suppression.** DECISION-26 iv rules out `except Exception` plus `noqa`. A test walks an escaped traceback's frames for the token.

## Design (the relay, in 40 lines)

**The choice: (A), a thin authenticating reverse proxy inside `magent serve`.** It is mounted at `/relay/<name>/mcp` and forwards to a LOOPBACK streamable-HTTP backend.
- V3 settles it. stealthy's backend already speaks the exact transport a node's `{type: http}` entry consumes.
- The only missing pieces are reachability (the backend binds loopback) and authentication (V4: it has none). A reverse proxy adds exactly those two things and nothing else.
- serve is already the process that is always up, binds loopback plus the Tailscale IP, and is supervised by `attention -d`. The relay adds no new port, no new bind and no new daemon.

**(B), a stdio-to-HTTP bridge, is YAGNI here and harmful.**
- For stealthy it would wrap a stdio proxy (V2) around the very HTTP backend we can reach directly. That is two hops to recover one.
- Serving N node sessions would mean N resident Python proxy processes on a PC that is already out of RAM. It would also mean re-implementing MCP session and request-id demultiplexing that streamable HTTP gives us for free (`Mcp-Session-Id`).
- A generic stdio bridge is only needed for a stdio server with NO HTTP backend. No such server is asked for. Such a server is classified `unrelayable` with that reason, so it stays visible rather than silently dropped.

**The mechanics:**
- `proxy` forwards `GET` (the SSE stream), `POST` (JSON-RPC) and `DELETE` (session end) with these headers: `Content-Type`, `Accept`, `Mcp-Session-Id`, `Mcp-Protocol-Version`, `Last-Event-Id`.
- It rewrites `Host` to the loopback backend and drops everything else, including `Origin` and the node's `Authorization`.
- It adds, upstream only, the PC entry's own `headers` for a loopback-`http` entry (for example `discord-mcp`'s key). That key never leaves the PC.
- The response streams with `HTTPResponse.read1` and a flush per chunk, close-delimited over serve's HTTP/1.0 (V11). An SSE event reaches the node when the backend emits it, not when the stream ends (Task 7 pins this with a held-open stream).
- A dead backend is `502 {"ok": false, "error": "backend down: <why>"}`, where `<why>` is stealthy's own words (V7).

**Why the relay is token-gated when the upload endpoints are not (the DESIGN.md §2 entry, Task 14).**
- The "no auth token by design" law is scoped to what it protects. The upload page, `/api/flash` and `/focus` let a tailnet peer drop an image into `~/.magent/uploads`, paste it into a pane, or flash a status line. That is a bounded, visible, low-value capability, and the loopback-plus-Tailscale bind is a proportionate control for it.
- The relay is a different class of object. It is remote control of this PC's logged-in browser profiles: navigate, read cookies, run script, as the user, on every site they are signed into. That is credential-equivalent.
- It is also consumed from SHARED machines. Nodes host per-person Unix users, and every tailnet device can reach the Tailscale IP, so "on the tailnet" is no longer "this person".
- stealthy's own authors made the same call (V4): unauthenticated only because it is loopback-only.
- Therefore every relay request needs `Authorization: Bearer <token>`, checked with `hmac.compare_digest`, and loopback is not exempt (K6).
- The token is never in argv, a URL or a log line. It travels once, inside the 0600 provisioning tarball.
- The upload endpoints stay exactly as they are. The relay does not widen the default bind, and no token is added to the upload routes.

**Cloud sessions get no relay in 3.20.0 (K10).**
- Reaching one would take a public Funnel plus a Custom allowlist that the user edits by hand.
- magent runs no `tailscale funnel`, reads no Funnel status, and builds no public URL.
- Plan J prints `mcp_relay.CLOUD_UNREACHABLE` so the gap is named, not silent.
- The relay reaches tailnet nodes only, through serve's existing loopback-plus-Tailscale bind.

```python
"""The MCP relay: ``magent serve`` fronting a PC-bound MCP server for nodes.

A node's Claude Code cannot reach a stdio server or a loopback URL on this PC
(DECISION-12; ``nodes.mcp_skip_reason``). For each server named in
``settings.mcpRelay`` a node instead gets an ``http`` entry pointing at
``/relay/<name>/mcp`` on this PC's serve, and serve forwards each request to
that server's loopback streamable-HTTP backend.

Token-gated, unlike every other serve route -- DESIGN.md §2 "The relay is
token-gated; the upload page is not". The token is never in argv, a URL or a
log line, and loopback is not trusted (anything tailscaled proxies arrives
from 127.0.0.1). Cloud sessions get no relay (plan K, K10): no Funnel code.

A leaf over ``log``, ``env``, ``config``, ``nodes`` and ``tailnet``: no cli
import (LS-A-001).
"""

from __future__ import annotations

import contextlib
import hmac
import os
import re
import secrets
from pathlib import Path

from magent.config import RELAY_NAME_RE
from magent.log import get_logger

RELAY_PREFIX = "/relay/"
# The ops-CLI name and the stdio-front name of the stealth browser (V1).
STEALTHY_FRONT = "stealth-chrome-devtools-mcp"
TOKEN_BYTES = 32
_TOKEN_CHARS = re.compile(r"^[A-Za-z0-9_-]{40,}$")


class RelayError(ValueError):
    """A relay name that cannot be both a URL path segment and a file name."""


def check_name(name: str) -> str:
    if not RELAY_NAME_RE.match(name):
        raise RelayError(
            (
                f"invalid relay name {name!r}: 1-64 characters of letters, "
                "digits, '.', '_' and '-'"
            )
        )
    return name


def token_path(name: str, *, home: Path | None = None) -> Path:
    """Call-time ``Path.home()`` on purpose: nothing here is import-bound, so
    tests/conftest.py's HOME redirect covers it without an _IMPORT_BOUND_PATHS
    entry."""
    return (home or Path.home()) / ".magent" / "relay" / f"{check_name(name)}.token"


def read_token(name: str, *, home: Path | None = None) -> str | None:
    """The stored token, or None. Never creates anything."""
    try:
        text = token_path(name, home=home).read_text(encoding="ascii").strip()
    except (OSError, UnicodeDecodeError):
        return None
    return text if _TOKEN_CHARS.match(text) else None


def _mint(path: Path) -> None:
    """Write a fresh token into a NEW file (``FileExistsError`` if one exists).

    O_EXCL + mode 0o600 at creation: the file is never world-readable, not
    even for the instant between a write and a chmod. (On Windows the mode is
    ignored and the file inherits the user-profile ACL, which is owner-only.)

    The token goes from ``secrets`` straight into ``os.write`` and is never
    bound to a name in any Python frame. A failed write (a full disk) raises
    through serve's supervisor into ``log.exception``, or through a CLI into
    Sentry's excepthook. Both hand every frame's locals to Sentry (V14), and
    no frame here holds the token (K8)."""
    fd = os.open(path, os.O_WRONLY | os.O_CREAT | os.O_EXCL, 0o600)
    try:
        os.write(fd, secrets.token_urlsafe(TOKEN_BYTES).encode("ascii"))
    finally:
        os.close(fd)


def ensure_token(name: str, *, home: Path | None = None) -> str:
    """The token for ``name``, generated once and reused (K3). Race-safe
    between serve and a provisioning CLI: whoever loses O_EXCL reads the
    winner's token. The answer is always what is ON DISK, which is what
    serve's ``fresh_token`` honours."""
    existing = read_token(name, home=home)
    if existing:
        return existing
    path = token_path(name, home=home)
    path.parent.mkdir(parents=True, exist_ok=True)
    with contextlib.suppress(FileExistsError):  # raced: read the winner's below
        _mint(path)
    stored = read_token(name, home=home)
    if stored:
        return stored
    get_logger("upload").warning("mcp relay: replacing an unreadable token file for %s", name)
    path.unlink(missing_ok=True)
    _mint(path)
    stored = read_token(name, home=home)
    if stored is None:
        raise RelayError(f"could not store a relay token for {name}")
    return stored


def relay_base(host: str, *, port: int) -> str:
    return f"http://{host}:{port}{RELAY_PREFIX.rstrip('/')}"


def relay_url(name: str, base: str) -> str:
    """``base`` is ``relay_base(<tailscale ip>, port=...)``."""
    return f"{base}/{check_name(name)}/mcp"


def parse_route(path: str) -> tuple[str, str] | None:
    """``/relay/<name>/mcp[/]`` -> (name, "mcp"); ``/relay/<name>/health`` ->
    (name, "health"); anything else None."""
    if not path.startswith(RELAY_PREFIX):
        return None
    name, _, tail = path[len(RELAY_PREFIX) :].partition("/")
    if not RELAY_NAME_RE.match(name):
        return None
    leaf = tail.rstrip("/")
    return (name, leaf) if leaf in ("mcp", "health") else None


def authorized(header: str | None, token: str | None) -> bool:
    """Constant-time ``Authorization: Bearer <token>`` check."""
    if not header or not token:
        return False
    scheme, _, value = header.strip().partition(" ")
    if scheme.lower() != "bearer":
        return False
    return hmac.compare_digest(value.strip().encode(), token.encode())
```

```python
@dataclass(frozen=True)
class Backend:

    loopback-http entry's own; the headers are sent UPSTREAM only and never
    shipped to a node. ``reason`` says why a KIND_NONE name is not relayed --

        data = json.loads((home / ".claude.json").read_text(encoding="utf-8"))
    except (OSError, ValueError):
        return {}
    servers = data.get("mcpServers") if isinstance(data, dict) else None
    return dict(servers) if isinstance(servers, dict) else {}


def _command_base(command: object) -> str:
    if not isinstance(command, str):
        return ""
    base = command.replace("\\", "/").rsplit("/", 1)[-1].lower()
    return base.removesuffix(".exe")

def plan_relay(name: str, spec: object) -> Backend:
    """Classify by transport FIRST (DECISION-16). F's ``mcp_skip_reason`` is
    consulted only for a url server. A PORTABLE stdio spec, which F's table
    ships as a node-probed candidate (``command -v``), is still judged here,
    so a relayed name can never fall through to "PC-local" or "not on the
    node"."""
    if not isinstance(spec, dict):
        return Backend(name, KIND_NONE, reason=NOT_ON_THIS_PC)
    declared = spec.get("type")
    kind = declared if isinstance(declared, str) and declared else ("stdio" if "command" in spec else "http")
    if kind == "stdio":
        if _command_base(spec.get("command")) == STEALTHY_FRONT:
            return Backend(name, KIND_STEALTHY)
        return Backend(
            name, KIND_NONE, reason="a stdio server with no HTTP backend (a stdio bridge is not built)"
        )
    skip = nodes.mcp_skip_reason(spec)
    if skip is None:
        return Backend(name, KIND_NONE, reason=SHIPS_AS_IS)
    if kind != "http":
        return Backend(name, KIND_NONE, reason=f"an {kind} server (only streamable HTTP is relayed)")
    url = spec.get("url")
    if skip != nodes.MCP_LOOPBACK_REASON or not isinstance(url, str):
        return Backend(name, KIND_NONE, reason=skip)
    raw = spec.get("headers", {})
    if not isinstance(raw, dict) or not all(
        isinstance(k, str) and isinstance(v, str) for k, v in raw.items()
    ):
        return Backend(name, KIND_NONE, reason="its headers are not a string map")
    if any("${" in v for v in raw.values()):
        return Backend(
            name, KIND_NONE, reason="its headers use ${VAR} expansion, which the relay does not perform"
        )
    return Backend(name, KIND_HTTP, url=url, headers=tuple(sorted(raw.items())))
```

```python
_BACKEND_LINE = re.compile(r"^backend\s*:\s*(?P<text>.+?)\s*$", re.MULTILINE)

def find_stealthy() -> str | None:
    """THE resolver of the stealthy ops CLI. Every test sees None
    (tests/conftest.py ``_no_real_stealthy``)."""
    return shutil.which("stealthy")


def _run_stealthy(args: list[str], timeout_s: float) -> tuple[int | None, str]:
    """(rc, stdout). rc 127 = not installed, None = timed out, 126 = spawn
    failed. Bounded like remote_mux._spawn: the interpreter behind a shim is a
    grandchild that can hold the pipe, so a timed-out child is reaped, never
    communicate()d twice."""
    exe = find_stealthy()
    if exe is None:
        return (127, "")
    try:
        proc = subprocess.Popen(
            [exe, *args],
            stdin=subprocess.DEVNULL,
            stdout=subprocess.PIPE,
            stderr=subprocess.DEVNULL,
            creationflags=_SPAWN_FLAGS,
        )
    except OSError:
        return (126, "")
    try:
        out, _ = proc.communicate(timeout=timeout_s)
    except subprocess.TimeoutExpired:
        proc.kill()
        with contextlib.suppress(subprocess.TimeoutExpired, OSError):
            proc.wait(timeout=_REAP_TIMEOUT_S)
        return (None, "")
    return (proc.returncode, out.decode("utf-8", errors="replace"))
```

```python
def tcp_alive(url: str, *, timeout_s: float = PROBE_TIMEOUT_S) -> bool:
    parts = urlsplit(url)
    try:
        with socket.create_connection(
            (parts.hostname or "127.0.0.1", parts.port or 80), timeout=timeout_s
        ):
            return True
    except OSError:
        return False


@dataclass(frozen=True)
class Route:
    backend: Backend
    token: str | None


class RelayState:
    """serve's one view of its relays.

    ``load`` (the supervisor thread, every RELAY_SUPERVISE_INTERVAL_S) replaces
    the name->Route table whole. ``ensure_relay_backend`` resolves the stealth
    backend lazily on the request path, under one lock, so concurrent requests
    share one cold start and an unused relay costs no subprocess at all.
    magent never starts a backend any other way, and never kills, restarts or
    evicts one (K2).
    """

    def __init__(
        self, *, home: Path | None = None, now: Callable[[], float] = time.monotonic
    ) -> None:
        self._home = home
        self._now = now
        self._table_lock = threading.Lock()
        self._routes: dict[str, Route] = {}
        self._stealthy_lock = threading.Lock()
        self._stealthy_url: str | None = None
        self._last_start: float | None = None

    def load(self, names: Sequence[str], servers: Mapping[str, object]) -> None:
        routes: dict[str, Route] = {}
        for name in names:
            backend = plan_relay(name, servers.get(name))
            token = None if backend.kind == KIND_NONE else ensure_token(name, home=self._home)
            routes[name] = Route(backend, token)
        with self._table_lock:
            self._routes = routes

    def route(self, name: str) -> Route | None:
        with self._table_lock:
            return self._routes.get(name)

    def fresh_token(self, name: str) -> str | None:
        """Re-read on a mismatch: a token rotated by provisioning is honoured
        without restarting serve (K3)."""
        return read_token(name, home=self._home)

    def cached_stealthy_url(self) -> str | None:
        return self._stealthy_url

    def forget_stealthy(self) -> None:
        with self._stealthy_lock:
            self._stealthy_url = None

    def check_cached(self) -> None:
        url = self._stealthy_url
        if url is not None and not tcp_alive(url):
            get_logger("upload").info("mcp relay: stealth backend %s stopped answering", url)
            self.forget_stealthy()

    def ensure_relay_backend(self, backend: Backend) -> tuple[str | None, str]:
        """(upstream url, why). ``why`` is shown to the node in a 502."""
        if backend.kind == KIND_HTTP:
            return (backend.url, "configured") if backend.url else (None, "no url")
        if backend.kind != KIND_STEALTHY:
            return (None, backend.reason or "not relayable")
        with self._stealthy_lock:
            if self._stealthy_url is not None and tcp_alive(self._stealthy_url):
                return (self._stealthy_url, "cached")
            self._stealthy_url = None
            status = stealthy_status()
            if status.port is None and status.text == NOT_RUNNING:
                now = self._now()
                if self._last_start is not None and now - self._last_start < ENSURE_COOLDOWN_S:
                    return (
                        None,
                        "stealthy backend: not running (a start was attempted under a minute ago)",
                    )
                self._last_start = now
                failed = start_stealthy_backend()
                if failed is not None:
                    return (None, failed)
                status = stealthy_status()
            if status.port is None:
                return (None, f"stealthy backend: {status.text}")
            self._stealthy_url = stealthy_url(status.port)
            return (self._stealthy_url, "resolved")
```

```python
"""A stdlib stand-in for an MCP streamable-HTTP backend, served in-process on
127.0.0.1:0. Not a fake binary (THE fake is _fake_ssh.py): it answers HTTP the
way stealthy's backend does -- JSON-RPC over POST, an event stream on demand,
Mcp-Session-Id both ways -- and records what reached it."""

from __future__ import annotations

import json
import threading
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer
from typing import ClassVar


class _Backend(BaseHTTPRequestHandler):
    protocol_version = "HTTP/1.1"  # real backends answer chunked
    seen: ClassVar[list[dict[str, object]]] = []
    release: ClassVar[threading.Event] = threading.Event()

    def _record(self, body: bytes) -> None:
        type(self).seen.append(
            {
                "method": self.command,
                "path": self.path,
                "headers": {k.lower(): v for k, v in self.headers.items()},
                "body": body,
            }
        )

    def _chunk(self, data: bytes) -> None:
        self.wfile.write(f"{len(data):X}\r\n".encode() + data + b"\r\n")
        self.wfile.flush()

    def do_POST(self) -> None:
        body = self.rfile.read(int(self.headers.get("Content-Length") or 0))
        self._record(body)
        msg = json.loads(body)
        if msg.get("method") in ("stream", "chunked"):
            self.send_response(200)
            kind = "text/event-stream" if msg["method"] == "stream" else "application/json"
            self.send_header("Content-Type", kind)
            self.send_header("Transfer-Encoding", "chunked")
            self.send_header("Mcp-Session-Id", "sess-1")
            self.end_headers()
            if msg["method"] == "stream":
                self._chunk(b"event: message\ndata: one\n\n")
                type(self).release.wait(10)
                self._chunk(b"event: message\ndata: two\n\n")
            else:
                self._chunk(b'{"jsonrpc":"2.0",')
                self._chunk(b'"id":1,"result":{}}')
            self.wfile.write(b"0\r\n\r\n")
            return
        out = json.dumps(
            {"jsonrpc": "2.0", "id": msg.get("id"), "result": {"echo": msg.get("params")}}
        ).encode()
        self.send_response(200)
        self.send_header("Content-Type", "application/json")
        self.send_header("Content-Length", str(len(out)))
        self.send_header("Mcp-Session-Id", "sess-1")
        self.end_headers()
        self.wfile.write(out)

    def do_DELETE(self) -> None:
        self._record(b"")
        self.send_response(200)
        self.send_header("Content-Length", "0")
        self.end_headers()

    def log_message(self, fmt: str, *args: object) -> None:
        return


class McpBackend:
    def __init__(self) -> None:
        _Backend.seen = []
        _Backend.release = threading.Event()
        self.server = ThreadingHTTPServer(("127.0.0.1", 0), _Backend)
        self.port = self.server.server_address[1]
        threading.Thread(target=self.server.serve_forever, daemon=True).start()

    @property
    def seen(self) -> list[dict[str, object]]:
        return _Backend.seen

    @property
    def release(self) -> threading.Event:
        return _Backend.release

    def close(self) -> None:
        _Backend.release.set()
        self.server.shutdown()
        self.server.server_close()
```

```python
UPSTREAM_CONNECT_TIMEOUT_S = 5.0
# An idle SSE stream longer than this ends; the MCP client re-opens it (the
# GET stream is resumable by design).
UPSTREAM_READ_TIMEOUT_S = 300.0
_CHUNK = 64 * 1024
# Forwarded in, in this exact set. Authorization is deliberately absent: the
# node's bearer token ends here.
_REQUEST_HEADERS = ("Content-Type", "Accept", "Mcp-Session-Id", "Mcp-Protocol-Version", "Last-Event-Id")
_RESPONSE_HEADERS = ("Content-Type", "Mcp-Session-Id", "Mcp-Protocol-Version", "Cache-Control", "Content-Length")


def _json(handler: BaseHTTPRequestHandler, status: int, payload: dict[str, object]) -> None:
    body = json.dumps(payload).encode()
    handler.close_connection = True
    handler.send_response(status)
    handler.send_header("Content-Type", "application/json")
    handler.send_header("Content-Length", str(len(body)))
    handler.end_headers()
    handler.wfile.write(body)


def proxy(
    handler: BaseHTTPRequestHandler,
    upstream: str,
    extra: tuple[tuple[str, str], ...],
    method: str,
    body: bytes | None,
) -> str:
    """Forward one request to ``upstream`` and stream the answer back.

    Returns an outcome word for the log line. Streams with ``read1`` + a flush
    per chunk, close-delimited (serve speaks HTTP/1.0, V11), so an SSE event
    reaches the node when the backend emits it. Host is rewritten to the
    backend; Origin and the node's Authorization never cross; ``extra`` (a
    loopback entry's own headers) goes upstream only.
    """
    parts = urlsplit(upstream)
    host = parts.hostname or "127.0.0.1"
    port = parts.port or 80
    path = parts.path or "/"
    query = urlsplit(handler.path).query
    if query:
        path = f"{path}?{query}"
    headers = {h: v for h in _REQUEST_HEADERS if (v := handler.headers.get(h)) is not None}
    headers.update(dict(extra))
    headers["Host"] = f"{host}:{port}"
    if body is not None:
        headers["Content-Length"] = str(len(body))
    conn = http.client.HTTPConnection(host, port, timeout=UPSTREAM_CONNECT_TIMEOUT_S)
    try:
        try:
            conn.connect()
            if conn.sock is not None:
                conn.sock.settimeout(UPSTREAM_READ_TIMEOUT_S)
            conn.request(method, path, body=body, headers=headers)
            resp = conn.getresponse()
        except OSError as exc:
            _json(handler, 502, {"ok": False, "error": f"backend unreachable ({type(exc).__name__})"})
            return "backend-unreachable"
        handler.close_connection = True
        handler.send_response(resp.status)
        for name in _RESPONSE_HEADERS:
            value = resp.getheader(name)
            if value is not None:
                handler.send_header(name, value)
        handler.send_header("Connection", "close")
        handler.end_headers()
        try:
            while chunk := resp.read1(_CHUNK):
                handler.wfile.write(chunk)
                handler.wfile.flush()
        except OSError:
            return f"{resp.status} stream-cut"
        return str(resp.status)
    finally:
        conn.close()
```

```python
MAX_BODY_BYTES = 16 * 1024 * 1024
_METHODS = ("GET", "POST", "DELETE")


def _health(handler: BaseHTTPRequestHandler, name: str, state: RelayState, route: Route) -> None:
    passive = "passive=1" in urlsplit(handler.path).query.split("&")
    if passive and route.backend.kind == KIND_STEALTHY:
        cached = state.cached_stealthy_url()
        if cached is None or not tcp_alive(cached):
            _json(handler, 503, {"ok": False, "name": name, "error": "idle: resolves on first use"})
            return
        _json(handler, 200, {"ok": True, "name": name, "backend": "reachable"})
        return
    upstream, why = state.ensure_relay_backend(route.backend)
    if upstream is not None and tcp_alive(upstream):
        _json(handler, 200, {"ok": True, "name": name, "backend": "reachable"})
        return
    detail = why if upstream is None else "not answering"
    _json(handler, 502, {"ok": False, "name": name, "error": f"backend down: {detail}"})


def _read_body(handler: BaseHTTPRequestHandler) -> bytes | int:
    """The POST body, or the status to refuse it with."""
    raw = handler.headers.get("Content-Length")
    if raw is None:
        return 411
    try:
        length = int(raw)
    except ValueError:
        return 400
    if length < 0:
        return 400
    if length > MAX_BODY_BYTES:
        return 413
    return handler.rfile.read(length)


def handle(
    handler: BaseHTTPRequestHandler,
    method: str,
    state: RelayState | None,
    *,
    drain: Callable[[], None],
) -> None:
    """Serve one ``/relay/...`` request on ``handler``. ``state`` None means
    the relay is off (every route is a 404). ``drain`` is serve's bounded
    body drain, run before any refusal of an unread body (the Windows RST
    law, upload_server's "Rejected-request drain" note).

    Never logs a header. It catches the expected failures of a proxied
    request and logs their class only. Anything else is a bug: it propagates
    to serve's own crash log, a ``log.exception`` that hands every frame's
    locals to Sentry. So no frame here holds a token. The header lives only
    in ``_refusal``, which cannot raise, and ``Route`` hides its token from
    repr (K8, DECISION-26 iv).
    """
    log = get_logger("upload")
    path = urlsplit(handler.path).path
    parsed = parse_route(path)
    route = state.route(parsed[0]) if (state is not None and parsed is not None) else None
    if state is None or parsed is None or route is None:
        drain()
        _json(handler, 404, {"ok": False, "error": "no such relay"})
        log.info("relay %s %s -> 404", method, path)
        return
    name, leaf = parsed
    if route.backend.kind == KIND_NONE:
        drain()
        _json(handler, 404, {"ok": False, "error": f"{name} is not relayable: {route.backend.reason}"})
        log.info("relay %s %s -> 404 (unrelayable)", name, method)
        return
    try:
        refusal = _refusal(handler, name, route, state)
        if refusal is not None:
            drain()
            _json(handler, 401, {"ok": False, "error": "unauthorized"})
            log.warning("relay %s %s -> 401 (%s)", name, method, refusal)
            return
        if method not in _METHODS or (leaf == "health" and method != "GET"):
            drain()
            _json(handler, 405, {"ok": False, "error": "Method not allowed"})
            return
        if leaf == "health":
            _health(handler, name, state, route)
            return
        body: bytes | None = None
        if method == "POST":
            read = _read_body(handler)
            if isinstance(read, int):
                _json(handler, read, {"ok": False, "error": "a relayed POST needs a Content-Length within bounds"})
                log.warning("relay %s POST -> %d", name, read)
                return
            body = read
        upstream, why = state.ensure_relay_backend(route.backend)
        if upstream is None:
            drain()
            _json(handler, 502, {"ok": False, "error": f"backend down: {why}"})
            log.warning("relay %s %s -> 502 (%s)", name, method, why)
            return
        outcome = proxy(handler, upstream, route.backend.headers, method, body)
        if outcome == "backend-unreachable" and route.backend.kind == KIND_STEALTHY:
            state.forget_stealthy()
        log.info("relay %s %s -> %s", name, method, outcome)
    except (OSError, ValueError, http.client.HTTPException) as exc:
        # A proxied request's expected failures: a client or upstream socket
        # gone (OSError), a malformed frame (ValueError), a broken upstream
        # reply (HTTPException). Class only, no exc_info (K8).
        log.error("relay %s %s failed: %s", name, method, type(exc).__name__)
        with contextlib.suppress(OSError):
            _json(handler, 500, {"ok": False, "error": "internal"})


def _refusal(handler: BaseHTTPRequestHandler, name: str, route: Route, state: RelayState) -> str | None:
    """None when the request carries this relay's token, else why not.

    The ONLY frame that ever holds the Authorization header. Nothing in it
    can raise: ``authorized`` is pure, and the one file read is caught. So
    the header never rides a traceback to Sentry (K8)."""
    header = handler.headers.get("Authorization")
    if authorized(header, route.token):
        return None
    try:
        fresh = state.fresh_token(name)
    except (OSError, ValueError):
        fresh = None
    if authorized(header, fresh):
        return None
    return "token rejected" if header else "no token"
```

```python
def _supervise_mcp_relay(
    state: mcp_relay.RelayState,
    config_path: str | None,
    stop_event: threading.Event,
    interval: float = mcp_relay.RELAY_SUPERVISE_INTERVAL_S,
) -> None:
    """Keep serve's relay table current: reload settings.mcpRelay and
    ~/.claude.json, mint any missing token, drop a stealth backend that
    stopped answering. A TCP probe at most -- never a subprocess (the stealth
    backend is resolved lazily on the request path, mcp_relay.RelayState).
    Every failure is a log line and another try next interval."""
    if not mcp_relay.relay_enabled():
        return
    log = get_logger("upload")
    while True:
        try:
            names = _relay_names(config_path)
            state.load(names, mcp_relay.relayed_servers(names, Path.home()))
            state.check_cached()
        except (OSError, ValueError) as exc:
            # Expected: a token file that cannot be written (a full disk, a
            # read-only home), an unreadable ~/.claude.json. Class only, no
            # exc_info: ensure_token runs inside load (K8).
            log.error("mcp relay: refresh failed: %s", type(exc).__name__)
        except Exception:
            # A bug. The same survival shape as serve's other supervisors, and
            # its traceback carries no secret. No relay frame binds a token
            # (mcp_relay._mint), Route.token and Backend.headers are out of
            # repr, and load sees only the relayed entries.
            log.exception("mcp relay: refresh failed")
        if stop_event.wait(interval):
            return
```

```python
HEALTH_TIMEOUT_S = 2.0


@dataclass(frozen=True)
class RelayRow:
    name: str  # "*" for a row about the relay as a whole
    level: str  # "ok" | "warn" -- never "fail": the relay can't break a PC
    detail: str


def _probe_health(port: int, name: str, token: str, *, passive: bool) -> RelayRow:
    path = f"{RELAY_PREFIX}{name}/health" + ("?passive=1" if passive else "")
    conn = http.client.HTTPConnection("127.0.0.1", port, timeout=HEALTH_TIMEOUT_S)
    try:
        conn.request("GET", path, headers={"Authorization": f"Bearer {token}"})
        resp = conn.getresponse()
        body = resp.read()
    except OSError:
        return RelayRow(name, "warn", f"magent serve is not answering on 127.0.0.1:{port}")
    finally:
        conn.close()
    if resp.status == 200:
        return RelayRow(name, "ok", "relayed (backend reachable)")
    if resp.status == 503:
        return RelayRow(name, "ok", "idle (resolves on first use)")
    if resp.status == 502:
        try:
            error = json.loads(body).get("error", "backend down")
        except ValueError:
            error = "backend down"
        return RelayRow(name, "warn", str(error))
    if resp.status == 401:
        return RelayRow(name, "warn", "serve rejected this PC's own token (restart magent serve)")
    if resp.status == 404:
        return RelayRow(name, "warn", "serve does not relay it yet (restart magent serve)")
    return RelayRow(name, "warn", f"unexpected HTTP {resp.status} from the relay")


def local_report(settings: Settings, *, home: Path, passive: bool = False) -> list[RelayRow]:
    """The relay as ``status`` (passive: never resolves a backend) and
    ``doctor`` (active: what a node's first request would do) see it."""
    if not relay_enabled():
        return [RelayRow("*", "ok", "off (MAGENT_MCP_RELAY=0)")]
    names = list(settings.mcp_relay)
    if not names:
        return [RelayRow("*", "ok", "no servers listed in settings.mcpRelay")]
    if not settings.upload_server:
        return [RelayRow("*", "warn", "settings.uploadServer is off; the relay rides magent serve")]
    rows: list[RelayRow] = []
    pc = pc_mcp_servers(home)
    for name in names:
        backend = plan_relay(name, pc.get(name))
        if backend.kind == KIND_NONE:
            if backend.reason == NOT_ON_THIS_PC:
                rows.append(RelayRow(name, "ok", "not on this PC (nothing to relay)"))
            else:
                rows.append(RelayRow(name, "warn", backend.reason or "not relayable"))
            continue
        # READ-ONLY: doctor and status mint nothing. The token is passed
        # inline, never bound in this frame (K8).
        if read_token(name, home=home) is None:
            rows.append(
                RelayRow(name, "warn", "no relay token yet: magent serve mints it on its next refresh (is serve running?)")
            )
            continue
        rows.append(_probe_health(settings.upload_port, name, read_token(name, home=home) or "", passive=passive))
    return rows
```

```python
def probe_relay(node: Node, url: str, token: str, *, timeout_s: float) -> tuple[str, str]:
    """GET the PC relay's health route FROM ``node``. The token rides curl's
    config-on-stdin (-K -), never argv: a shared node's other users can read
    argv in ps (plan K, K5). Returns (level, detail); never raises."""

    try:
        proc = run(node, _RELAY_PROBE, timeout_s=timeout_s, input_bytes=config, check=False)
    except RemoteError as e:

    code = proc.stdout.decode("utf-8", "replace").strip()[-3:]
    if proc.returncode == 127:

    if code == "200":
        return ("ok", "relayed (backend reachable)")
    if code == "401":

    if code in ("000", ""):

    return ("warn", f"unexpected HTTP {code} from the PC's relay")
```
