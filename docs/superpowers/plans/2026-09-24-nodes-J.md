# Nodes sub-plan J: the cloud backend (`"node": "cloud"`)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A project pinned to `"node": "cloud"` opens as a LOCAL psmux pane that runs `claude --cloud "<cloudTask>"`, branded `@cloud`. It is created at most once, only from a clean, pushed GitHub checkout, and only after the project's push set (`.env*` and the other gitignored files) has reached the cloud. The push set travels SEALED: `age`-encrypted on the PC, published as a lone commit on `refs/magent/sealed` in the project's own GitHub repo, and unsealed at session start by a magent-generated plugin the user uploads to claude.ai once. A manual copy-paste fallback covers every case sealing cannot. The session comes home with `claude --teleport`.

**Architecture:** One new leaf, `cloud_plugin.py`, renders the magent-cloud plugin. `config.py` gains `cloudTask`; the `is_cloud`/`runs_on_node` split comes from D (DECISION-22), and J1 adds it only if D did not. `sessions/claude.py` builds the pane command. `nodes.py` gains the pure cloud checks, the push-set digest and the in-memory seal archive; it never spawns a process (DECISION-26 vi). `remote_mux.py`, the leaf that already shells out, gains the `age`/`age-keygen`/`git push`/`gh` calls behind one `_tool` seam, guarded in tests by F's `_no_real_gh` and a new autouse `_no_real_age`. `psmux.py` and `platform/windows.py` learn "never re-send" and "brand with a nick". `launch.py` gains the create gate. The surfaces (status, sessions, attach, fleet, upload/Alt+V, node push/recall/cloud-setup, doctor) each get one narrow branch.

**Tech Stack:** Python 3.10+ stdlib, click, the Claude Code CLI 2.1.280 (`--cloud`, `--teleport`), and the external `age`/`age-keygen` binaries (FiloSottile/age, `winget install FiloSottile.age`) resolved off PATH through one seam. `age` is an optional runtime tool, not a Python dependency: without it, `node push` falls back to the manual tier.

**Worktree:** `<scratch>/wt-nodes-j`, branched from `feat/nodes` AFTER PR-B, PR-D, PR-G and PR-K merge. J1–J3, J3m and J6 need only B; J4 needs nothing. J7–J9 edit D's lines. J11m and J11s edit G's `node_cmd.py`. J7 and J8 import K's `mcp_relay.CLOUD_UNREACHABLE` directly (DECISION-16 item 5); it always exists at the J base. Tasks are BUILT in the order of "Build order and the J0-B gate" below (DECISION-18), not in number order. First command: `uv sync --extra dev`.

## §18 The cloud backend (`"node": "cloud"`)

1. **Built-in nick.** `node: "cloud"` needs no pool entry. A pool entry named `cloud` is a ConfigError, and so is `cloud` + `host` [V23]. A cloud project runs tool `claude` and carries `cloudTask`, the task text the session starts on. The text must never look like a session id or URL, because `--cloud <id|url>` attaches instead of creating [V1].
2. **The environment is chosen outside magent.** `--environment` takes only self-hosted `ccpool_` ids [V2]. Self-hosted environments are a Team/Enterprise beta [V43]. The hosted environment is the user's `/remote-env` pick or `remote.defaultEnvironmentId` [V14][V39]. Environments are created and edited only in the claude.ai/code dialog [V14]. There is no `cloudEnvironment` field.
3. **D7, verbatim.** Git is the truth. The VM clones the GitHub remote at the checkout's branch [V7], and work comes home by `git pull` + teleport [V12]. A create is refused on: no remote or a non-GitHub remote [V8]; a detached HEAD; uncommitted or unpushed work, which the clone would not contain [V7]. magent never sets `CCR_FORCE_BUNDLE` and never passes `--allow-dirty`.
4. **Pin-only.** `auto` never places onto cloud: `cloud` is not a pool member [V23].
5. **The pane.** It is a LOCAL psmux session running `cmd /c claude --cloud "<cloudTask>"` [V19], branded through D's `status_left("cloud")` (" magent @cloud ", 15 cells, status-left-length 17) [V20]. Every `--cloud` makes a NEW session [V10], so the pane is typed exactly once: no re-send, no revive [V19]. The create gate runs only when no psmux session exists yet.
6. **Still works:** `attach`; F2, which opens the LOCAL checkout; `peek`; `down`, which kills only the local pane (the cloud session persists [V11], and `down` says so); rows in `status`, `up --json` and `sessions --json`, which carry `"node": "cloud"`.
7. **Refused, with a reason.**
   - **Alt+V and the phone page:** the image would land on the PC. `serve` answers 409 and Alt+V narrates `cloud-pane` [V21].
   - **`send`/`model`:** they would type into a viewer. `send` names `claude -p "<msg>" --cloud <session-id>` [V5].
   - **`attach --no-mux`:** it would create a second session.
8. **Not applicable:** provision, ssh shipping, sync/pull, placement, node-map, tmux `--mux`, and D's Remote-SSH F2. The MCP relay (DECISION-16) is not reachable from a cloud session in 3.20.0; the bring-up prints `mcp_relay.CLOUD_UNREACHABLE` when `settings.mcpRelay` is non-empty; a cloud session's MCP config is never written by magent, so nothing else changes; ledgered in DESIGN.md (K owns the row).
9. **Recall.** `magent node recall <p> --local` prints `cd`, `git pull` and `claude --teleport <id>` when an id is visible in the pane, else the bare picker [V13]. Teleport needs a clean tree, the same repo, the branch pushed and the same account [V12]. The copy is independent, and `--to <nick>` is refused.
10. **What can carry a secret or file into a cloud session (DECISION-8).** No CLI or API writes any of these [V4][V14]:
    - **Environment variables** are dialog-only `.env` text, copied once at start into ordinary process variables that any command can read. "Anyone who uses the environment can read the values," and a shared environment must hold no secrets [V14][V25][V26].
    - **API credentials** are Pro/Max only and need the admin role. The agent proxy adds a header for the listed hosts, and the key "never reaches Claude, the commands it runs, or the session's environment variables" [V15][V28].
    - **The setup script** is dialog-only. It runs as root before launch and is cached as a filesystem snapshot [V27]. It never gets API credentials [V28].
    - **Committed `.claude/settings.json` `env` or `.mcp.json`** is readable by anyone who reads the repo, so it is never used for secrets [V29].
    - **A plugin synced from claude.ai** runs its SessionStart hook in cloud after launch, on start and on resume, without touching the repo [V30][V31][V32][A: U7].
    - **`claude --cloud` itself** uploads nothing on the clone path. A bundle carries tracked changes but never untracked files [V7][V37]. Rule 3 makes the clone the only path.
11. **Decision: three tiers, safest first (DECISION-14, refined by DECISION-18).**
    - **a. API credential.** For a key used only as an HTTP header to a known host (Pro/Max), the value never enters the VM. magent names the candidates; the user adds them.
    - **b. Sealed (default, if J0-B passes).** `magent node push` tars the push-set files inside the project and encrypts them with `age` to a recipient made by `magent node cloud-setup`. It force-pushes the ciphertext as a lone commit to `refs/magent/sealed` in the project's own GitHub repo; no branch or working tree is touched [A: U8]. The magent-cloud plugin's SessionStart hook fetches it through the GitHub proxy [V36]. It decrypts with `MAGENT_UNSEAL`, the age identity and the ONE secret, pasted once into a personal environment. It extracts only paths the checkout gitignores. `age` is used because the stdlib has no authenticated cipher, and magent writes no crypto of its own. The VM gets `age` from one setup-script line; archive.ubuntu.com is on Trusted [V35]. If J0-B finds U7 or U8 failing, (b) is cut for 3.20.0 [DECISION-18].
    - **c. Manual (fallback; built first, and the default if (b) is cut).** Used when there is no key, no `age`, or a public or unknown-visibility repo. Names print masked; the full `KEY=value` block goes to a 0600 temp file for pasting into the dialog. Files other than `.env*` cannot travel.
    - **The create gate** passes once the current push set is sealed or handed off. The check is a keyed HMAC digest, never a value.
12. **Threat model.**
    - Anthropic can read the key and the plaintext in every tier except (a).
    - Sealed keeps values out of the environment config and out of the dialog. It rotates with one re-paste, via `cloud-setup --rotate`.
    - In (b) and (c), a prompt-injected agent in the VM can read both the plaintext and the key [V25][V34]. The hook appends `unset MAGENT_UNSEAL` to `CLAUDE_ENV_FILE` [V33], as defence in depth only [A: U11].
    - A leaked key opens every sealed set of that user until rotation.
    - A public repo means public ciphertext, so sealing is refused there.
    - **Rejected:** decrypting in the setup script (the snapshot would keep the plaintext [V27]); a gist (not on Trusted, and the proxy's API scope is attached repos [V36]); pulling from the PC over the network (the PC must be online, and it would expose the PC).
13. **Durability, phone and Session 0.** The cloud session outlives the pane, the PC and the laptop [V11]; the VM is reclaimed after inactivity [V17]. The Claude app and claude.ai/code show and steer it [V11]. `/login` and `/web-setup` need a desktop terminal, because a browser from a Session-0 pane is invisible [V22]. `--cloud` needs a claude.ai sign-in and the `allow_remote_sessions` policy [V18].
14. **Impossible from the CLI.** The CLI cannot list, stop, archive or delete a cloud session [V4][V11]. It cannot create or edit an environment, variable, credential, setup script, network level or plugin upload [V14][A]. magent never pretends otherwise.
15. **Network.** Network access is set per ENVIRONMENT in its dialog (shared environments on the admin page), never per session [V35]. At every level, GitHub (through its proxy) and the Anthropic API stay reachable [V44], so the sealed fetch (item 11b) needs no network change. `age` installs from archive.ubuntu.com, which the default Trusted level allows [V35].
16. **MCP in cloud.** A cloud session's MCP servers come from the repo's `.mcp.json` (one repo), from synced plugins, and from claude.ai connectors. They never come from `~/.claude.json` or the environment config [V29][V31]. magent writes none of them: the magent-cloud plugin carries no `.mcp.json` (item 8). `"magent-cloud@synced": false` in the user `enabledPlugins` keeps the plugin out of the PC's and nodes' own sessions [V31].

```python
# A cloud project's task text reaches `claude --cloud "<task>"` through TWO
# parsers: psmux types `cmd /c <command>` into pwsh, then cmd.exe reads it. So
# the charset admits no metacharacter of either ($ ` " ' % ^ & | < > ; ( ) ! #)
# and no leading '-' (it would read as a flag). One rule, no quoting layer.
CLOUD_TASK_RE = re.compile(r"[A-Za-z0-9][A-Za-z0-9 ,._/:-]{0,199}")
# `claude --cloud <arg>` ATTACHES when <arg> is a session id or a claude.ai/code
# URL (claude --help, 2.1.280) -- such a task would never create anything.
_CLOUD_ID_LIKE = re.compile(r"^(?:session_|cse_)|://")

def is_cloud(proj: ProjectConfig) -> bool:
    """The project runs as a Claude cloud session (spec §18)."""
    return proj.node == NODE_CLOUD


def runs_on_node(proj: ProjectConfig) -> bool:
    """The project's session lives on a POOL machine (a nick, or "auto").

    The cloud backend is not a node: its pane is a LOCAL psmux window. Every
    "skip node projects" test in the product asks THIS, never ``proj.node``."""
    return proj.node not in (None, NODE_CLOUD)


def _check_cloud_projects(projects: list[ProjectConfig], default_tool: str) -> None:
    """Spec §18.1: a cloud project runs claude and names a safe task."""
    for i, proj in enumerate(projects):
        label = f"projects[{i}]"
        if not is_cloud(proj):
            if proj.cloud_task is not None:
                click.echo(
                    f'Warning: {label}.cloudTask is ignored: the project has no "node": "cloud"',
                    err=True,
                )
            continue
        tool = proj.tool or default_tool
        if tool != "claude":
            raise ConfigError(
                f"{label}: a cloud project runs Claude Code; its tool is {tool!r}"
            )
        task = proj.cloud_task
        if task is None:
            raise ConfigError(
                f'{label}: "node": "cloud" needs "cloudTask", the task the cloud session starts on'
            )
        if _CLOUD_ID_LIKE.search(task):
            raise ConfigError(
                f"{label}.cloudTask must not be a session id or URL: claude would attach, not create"
            )
        if not CLOUD_TASK_RE.fullmatch(task):
            raise ConfigError(
                (
                    f"{label}.cloudTask must be 1-200 characters of letters, digits, "
                    "spaces and , . _ / : -, starting with a letter or digit"
                )
            )
        for key, value in (("windows", proj.windows), ("happy", proj.happy)):
            if value is not None:
                click.echo(
                    f"Warning: {label}.{key} is ignored on a cloud project", err=True
                )
```

```python
# The executable token of a configured claude command, typed into pwsh by
# psmux: no quotes, no spaces, no metacharacters (a path is fine).
_EXE_RE = re.compile(r"[A-Za-z0-9_.:\\/-]+")


def cloud_pane_command(base_cmd: str, task: str) -> str:
    """The one command a cloud pane runs: ``<exe> --cloud "<task>"`` (spec §18.5).

    Only the executable survives from ``base_cmd``: every flag there
    (``--continue``, ``--resume``, a model) belongs to a LOCAL conversation, and
    ``--cloud`` always starts a new one. Re-validates ``task`` against config's
    rule so no caller can type an unchecked string. Raises ValueError."""
    from magent.config import _CLOUD_ID_LIKE, CLOUD_TASK_RE

    parts = base_cmd.split()
    exe = parts[0] if parts else ""
    if not _EXE_RE.fullmatch(exe):
        raise ValueError(f"cannot type claude executable {exe!r} into a pane safely")
    if not CLOUD_TASK_RE.fullmatch(task) or _CLOUD_ID_LIKE.search(task):
        raise ValueError(f"unsafe cloud task {task!r}")
    return f'{exe} --cloud "{task}"'
```

```python
# --- the cloud backend (spec §18) ------------------------------------------


def cloud_git_refusal(state: LocalGitState) -> str | None:
    """Why ``claude --cloud`` must not start from this checkout, or None.

    The VM clones the GitHub remote at the checkout's branch and the work
    comes home by push + teleport (spec §18.3), so anything the clone would
    not contain, or could not push back to, is refused here."""
    branch = state.branch or "HEAD"
    if not state.url:
        return f"{state.path} has no git remote: the cloud session would have nowhere to push its work"
    if "github.com" not in state.url.lower():
        return "its remote is not on GitHub: a cloud session clones from and pushes back to GitHub only"
    if state.detached:
        return "HEAD is detached: check out the branch the cloud session should clone"
    if state.dirty:
        return f"{branch} has uncommitted changes: the cloud clones {branch} from GitHub, so commit and push first"
    if state.unpushed:
        return f"{branch} has unpushed commits: the cloud clones {branch} from GitHub, so push first"
    return None


_DOTENV_NAME = re.compile(
    r"^\s*(?:export\s+)?([A-Za-z_][A-Za-z0-9_]*)\s*=", re.MULTILINE
)


def dotenv_names(path: Path) -> tuple[str, ...]:
    """The variable NAMES a ``.env`` file defines, sorted -- never a value.

    Over-listing is the safe direction (a line inside a multi-line quoted value
    that looks like ``K=v`` adds a name the user can ignore); an unreadable
    file names nothing."""
    try:
        text = path.read_text(encoding="utf-8", errors="replace")
    except OSError:
        return ()
    return tuple(sorted(set(_DOTENV_NAME.findall(text))))


def _is_env_file(path: Path) -> bool:
    return path.name == ".env" or path.name.startswith(".env.")


@dataclass(frozen=True)
class CloudPushSet:
    """B's push set, read for a cloud project (spec §18.10-11).

    ``files`` sit inside the project and travel (sealed, or by hand for the
    ``.env*`` ones); ``outside`` files never reach a cloud session. Paths and
    names only: no field ever holds a value."""

    project_dir: Path
    files: tuple[Path, ...]
    outside: tuple[Path, ...]
    names: tuple[str, ...]

    @property
    def env_files(self) -> tuple[Path, ...]:
        return tuple(p for p in self.files if _is_env_file(p))

    @property
    def empty(self) -> bool:
        return not self.files and not self.outside

    def rel(self, path: Path) -> str:
        return path.relative_to(self.project_dir).as_posix()


def cloud_push_set(
    project_dir: Path,
    states: Sequence[LocalGitState],
    *,
    home: Path,
    extras: Sequence[str] = (),
) -> CloudPushSet:
    """Split B's push set into what travels and what cannot (spec §18.11)."""
    inside: list[Path] = []
    outside: list[Path] = []
    for path in push_set(project_dir, states, home=home, extras=extras):
        (inside if path.is_relative_to(project_dir) else outside).append(path)
    inside.sort(key=lambda p: p.relative_to(project_dir).as_posix())
    names: set[str] = set()
    for path in inside:
        if _is_env_file(path):
            names.update(dotenv_names(path))
    return CloudPushSet(
        project_dir=project_dir,
        files=tuple(inside),
        outside=tuple(sorted(outside)),
        names=tuple(sorted(names)),
    )


def _cloud_dir() -> Path:
    # Read at CALL time, so a test's monkeypatched NODES_DIR is honoured.
    # This is also E's `<nick>/` dir for nick "cloud" (DECISION-15). Every file
    # J keeps here is named `cloud-<x>.<ext>`: the dot means it can never be a
    # `<sid>/` dir (psmux.session_name turns "." into "-"), and none of the
    # names is in E's _RESERVED_NAMES (sessions.json, load.jsonl, pull.json,
    # node-map.json).
    return NODES_DIR / "cloud"


def _digest_key() -> bytes:
    """A random per-machine key, so a recorded digest is never a plain --
    and for a short secret, guessable -- hash of the file. Made once, 0600."""
    path = _cloud_dir() / "cloud-digest.key"
    try:
        key = path.read_bytes()
    except OSError:
        key = b""
    if len(key) == 32:
        return key
    path.parent.mkdir(parents=True, exist_ok=True)
    key = os.urandom(32)
    fd = os.open(path, os.O_WRONLY | os.O_CREAT | os.O_TRUNC, 0o600)
    with os.fdopen(fd, "wb") as fh:
        fh.write(key)
    return key


def push_set_digest(ps: CloudPushSet, mode: str) -> str:
    """HMAC-SHA256 over every travelling file's path AND bytes, every outside
    path, and the hand-off ``mode`` (an age recipient, or ``"manual"``).

    A changed value, a new file and a rotated key all change it; the record
    stores this and nothing else about the files."""
    mac = hmac.new(_digest_key(), digestmod=hashlib.sha256)
    mac.update(b"mode:" + mode.encode() + b"\n")
    for path in ps.files:
        mac.update(b"f:" + ps.rel(path).encode() + b"\n")
        try:
            mac.update(hashlib.sha256(path.read_bytes()).digest())
        except OSError:
            mac.update(b"unreadable")
    for path in ps.outside:
        mac.update(b"o:" + path.as_posix().encode() + b"\n")
    return mac.hexdigest()


def _records_path() -> Path:
    return _cloud_dir() / "cloud-records.json"


def _read_records() -> dict[str, dict[str, str]]:
    try:
        data = json.loads(_records_path().read_text(encoding="utf-8"))
    except (OSError, ValueError):
        return {}
    if not isinstance(data, dict):
        return {}
    records: dict[str, dict[str, str]] = {}
    for sid, rec in data.items():
        if isinstance(sid, str) and isinstance(rec, dict):
            records[sid] = {
                k: v
                for k, v in rec.items()
                if isinstance(k, str) and isinstance(v, str)
            }
    return records


def read_cloud_record(sid: str) -> dict[str, str] | None:
    """``{digest, mode, commit}`` of the last hand-off for ``sid``, or None."""
    return _read_records().get(sid)


def write_cloud_record(sid: str, *, digest: str, mode: str, commit: str = "") -> None:
    """Record a hand-off (tmp file + os.replace, like the node map)."""
    records = _read_records()
    records[sid] = {"digest": digest, "mode": mode, "commit": commit}
    path = _records_path()
    path.parent.mkdir(parents=True, exist_ok=True)
    tmp = path.with_suffix(".tmp")
    tmp.write_text(json.dumps(records, indent=2, sort_keys=True), encoding="utf-8")
    os.replace(tmp, path)


def read_recipient() -> str | None:
    """The age recipient ``magent node cloud-setup`` recorded, or None.

    Anything that is not an ``age1…`` public key -- above all an identity
    pasted into the wrong file -- reads as no recipient."""
    try:
        text = (
            (_cloud_dir() / "cloud-recipient.txt").read_text(encoding="utf-8").strip()
        )
    except OSError:
        return None
    return text if text.startswith("age1") else None


def write_recipient(recipient: str) -> None:
    path = _cloud_dir() / "cloud-recipient.txt"
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text(recipient + "\n", encoding="utf-8")


def cloud_env_refusal(
    sid: str, name: str, ps: CloudPushSet, recipient: str | None
) -> str | None:
    """Why the create must wait for ``magent node push``, or None (spec §18.11).

    Passes when nothing needs handing off, or when the record matches the
    CURRENT push set: sealed to the current recipient, or handed off by hand."""
    if ps.empty:
        return None
    rec = read_cloud_record(sid)
    if rec is not None:
        mode = rec.get("mode", "")
        current = mode == "manual" or (recipient is not None and mode == recipient)
        if current and rec.get("digest") == push_set_digest(ps, mode):
            return None
    shown = [*ps.names, *(ps.rel(p) for p in ps.files if not _is_env_file(p))]
    what = ", ".join(shown) or f"{len(ps.outside)} file(s) outside the project"
    return f"the push set ({what}) has not reached the cloud since it last changed; run: magent node push {name}"
```

```python
_DOTENV_LINE = re.compile(r"^\s*(?:export\s+)?([A-Za-z_][A-Za-z0-9_]*)\s*=\s*(.*)$")


def masked_lines(ps: CloudPushSet) -> list[str]:
    """``NAME  ******** (n chars)`` per variable, for the terminal (spec §18.11c)."""
    lengths: dict[str, int] = {}
    for path in ps.env_files:
        try:
            text = path.read_text(encoding="utf-8", errors="replace")
        except OSError:
            continue
        for line in text.splitlines():
            match = _DOTENV_LINE.match(line)
            if match:
                lengths[match.group(1)] = len(match.group(2).strip().strip("\"'"))
    return [f"{name}  ******** ({lengths[name]} chars)" for name in sorted(lengths)]


def write_private_temp(text: str, *, prefix: str, suffix: str = ".txt") -> Path:
    """``text`` in a fresh temp file only this user can read: mkstemp makes it
    0600 on POSIX; on Windows it inherits the per-user %TEMP% ACL [A]."""
    fd, name = tempfile.mkstemp(prefix=prefix, suffix=suffix)
    with os.fdopen(fd, "w", encoding="utf-8", newline="\n") as fh:
        fh.write(text)
    return Path(name)


def write_manual_handoff(ps: CloudPushSet) -> Path:
    """Every ``.env*`` file's text, verbatim, in ONE private temp file for
    pasting into the environment dialog. The caller deletes it on confirm."""
    parts = [
        "# magent: paste into claude.ai/code > environment settings > Environment variables\n"
    ]
    for path in ps.env_files:
        parts.append(f"# from {ps.rel(path)}\n")
        parts.append(
            path.read_text(encoding="utf-8", errors="replace").rstrip("\n") + "\n"
        )
    return write_private_temp("".join(parts), prefix="magent-cloud-env-", suffix=".env")
```

```python
class FakeTools:
    """Records (argv, stdin) and replies by the first argv token found in
    ``replies``. A token in ``fail_on`` raises SealError, like a tool exiting 1."""

    def __init__(
        self, replies: dict[str, bytes] | None = None, fail_on: str | None = None
    ) -> None:
        self.calls: list[tuple[list[str], bytes | None]] = []
        self.replies = replies or {}
        self.fail_on = fail_on

    def __call__(
        self, argv: list[str], *, data: bytes | None = None, step: str | None = None
    ) -> bytes:
        self.calls.append((argv, data))
        if self.fail_on is not None and self.fail_on in argv:
            raise remote_mux.SealError(f"{step or argv[0]} exited 1: refused")
        for token, out in self.replies.items():
            if token in argv:
                return out
```

```python
def seal_archive(ps: CloudPushSet) -> bytes:
    """A deterministic tar of the travelling files: sorted, mtime 0, owner 0,
    mode 0600, paths relative to the project."""
    buf = io.BytesIO()
    with tarfile.open(fileobj=buf, mode="w", format=tarfile.PAX_FORMAT) as tar:
        for path in ps.files:
            data = path.read_bytes()
            info = tarfile.TarInfo(ps.rel(path))
            info.size = len(data)
            info.mode = 0o600
            info.mtime = 0
            tar.addfile(info, io.BytesIO(data))
    return buf.getvalue()
```

```python
SEAL_TIMEOUT_S = 120.0


class SealError(RuntimeError):
    """Sealing or publishing failed. The message names the step, never a value."""


def _tool(
    argv: list[str], *, data: bytes | None = None, step: str | None = None
) -> bytes:
    """Run one external tool of the cloud hand-off (age, age-keygen, git) and
    return its stdout. THE seam tests replace (tests/unit/_fake_tools.py).

    Over ``_spawn``: bounded by SEAL_TIMEOUT_S, and stdin is logged as its
    length only. ``step`` names the call in an error (default: the exe name).
    Raises SealError."""
    label = step or Path(argv[0]).name
    try:
        proc = _spawn(
            argv,
            timeout_s=SEAL_TIMEOUT_S,
            input_bytes=data,
            check=False,
            shown=_redacted(argv, data),
        )
    except RemoteError as exc:
        raise SealError(f"{label} could not run ({exc.stderr_tail})") from exc
    if proc.returncode != 0:
        raise SealError(f"{label} exited {proc.returncode}: {_tail(proc.stderr)}")
    return proc.stdout


@functools.lru_cache(maxsize=1)
def find_age() -> str | None:
    """``age`` off PATH, or None. Tests never see the real one
    (tests/conftest.py::_no_real_age)."""
    return shutil.which("age")


@functools.lru_cache(maxsize=1)
def find_age_keygen() -> str | None:
    """``age-keygen`` off PATH, or None. Guarded like find_age."""
    return shutil.which("age-keygen")


def parse_keygen(out: str) -> tuple[str, str]:
    """(recipient, identity) from ``age-keygen`` output. Raises SealError."""
    recipient = identity = ""
    for line in out.splitlines():
        if line.lower().startswith("# public key:"):
            recipient = line.split(":", 1)[1].strip()
        elif line.startswith("AGE-SECRET-KEY-"):
            identity = line.strip()
    if not recipient.startswith("age1") or not identity:
        raise SealError("age-keygen printed no key pair")
    return recipient, identity


def age_keygen() -> tuple[str, str]:
    """A fresh (recipient, identity). The identity is RETURNED, never written
    here: the caller hands it to the user once (spec §18.11b). A seam tests
    replace."""
    exe = find_age_keygen()
    if exe is None:
        raise SealError("age-keygen is not on PATH: winget install FiloSottile.age")
    return parse_keygen(_tool([exe]).decode("utf-8", errors="replace"))


def seal(ps: CloudPushSet, recipient: str, *, age_exe: str) -> bytes:
    """``age -r <recipient>`` over ``nodes.seal_archive``: authenticated
    encryption by a maintained tool, because the stdlib has no AEAD and
    magent rolls none."""
    ciphertext = _tool([age_exe, "-r", recipient], data=seal_archive(ps), step="age")
    if not ciphertext:
        raise SealError("age produced no output")
    return ciphertext


def publish_sealed(
    repo: Path, remote_url: str, ciphertext: bytes, *, label: str
) -> str:
    """Write ``ciphertext`` as a lone commit and force-push it to SEALED_REF.

    Plumbing only: no branch, index or working-tree file is touched, and a
    re-seal replaces the ref. ``git -C``, because ``_spawn`` takes no cwd.
    Returns the commit sha. Raises SealError."""
    git = ["git", "-C", str(repo)]
    blob = _tool(
        [*git, "hash-object", "-w", "--stdin"], data=ciphertext, step="git hash-object"
    )
    tree = _tool(
        [*git, "mktree"],
        data=f"100644 blob {blob.decode().strip()}\t{SEALED_BLOB}\n".encode(),
        step="git mktree",
    )
    commit = (
        _tool(
            [
                *git,
                "-c",
                "user.name=magent",
                "-c",
                "user.email=magent@localhost",
                "commit-tree",
                tree.decode().strip(),
                "-m",
                f"magent: sealed push set for {label}",
            ],
            step="git commit-tree",
        )
        .decode()
        .strip()
    )
    _tool(
        [*git, "push", "--force", "--quiet", remote_url, f"{commit}:{SEALED_REF}"],
        step="git push",
    )
    return commit


_GITHUB_SLUG = re.compile(
    r"github\.com[:/]([^/\s]+/[^/\s]+?)(?:\.git)?/?$", re.IGNORECASE
)


def _github_slug(url: str) -> str | None:
    match = _GITHUB_SLUG.search(url)
    return match.group(1) if match else None


def repo_is_private(remote_url: str) -> bool | None:
    """True or False from ``gh repo view``; None when gh cannot tell. Every
    caller treats None as PUBLIC (spec §18.12). Over F's ``_gh``, so a test
    without a fake meets _no_real_gh, never the real gh. A seam tests replace."""
    slug = _github_slug(remote_url)
    if slug is None:
        return None
    proc = _gh(["repo", "view", slug, "--json", "isPrivate", "-q", ".isPrivate"])
    if proc is None or proc.returncode != 0:
        return None
    return {"true": True, "false": False}.get(
        proc.stdout.decode("utf-8", "replace").strip()
    )
```

```python
def project_for_session(config: MagentConfig, sid: str) -> ProjectConfig | None:
    """The configured project whose psmux session id is ``sid`` (the same
    title-or-leaf rule ``psmux.eligible_projects`` names sessions by)."""
    from magent.psmux import session_name

    for proj in config.projects:
        if session_name(proj.title or get_leaf_name(proj.path)) == sid:
            return proj
    return None


def cloud_session_ids(config: MagentConfig) -> set[str]:
    """Session ids of every cloud project (enabled or not)."""
    from magent.config import is_cloud
    from magent.psmux import session_name

    return {
        session_name(p.title or get_leaf_name(p.path))
        for p in config.projects
        if is_cloud(p)
    }


def cloud_refusal(config: MagentConfig, sid: str) -> str | None:
    """Why the cloud session for ``sid`` must NOT be created now, or None.

    Asked only right before a create -- never for a live session: every
    ``claude --cloud`` is a NEW cloud session (spec §18.5), so a refused create
    costs nothing and a wrong one costs a duplicate the CLI cannot list or stop.
    Gate, not advisory (plan J, "User decision")."""
    from magent import nodes, remote_mux
    from magent.config import is_cloud

    proj = project_for_session(config, sid)
    if proj is None or not is_cloud(proj):
        return None
    try:
        states = node_git_states(config, proj)
    except remote_mux.RemoteError as exc:
        return f"git could not read {proj.path} ({exc.stderr_tail.strip() or f'exit {exc.rc}'})"
    if not states:
        return f"{proj.path} is not a git repository: a cloud session clones one from GitHub"
    if len(states) > 1:
        return f"a cloud session runs ONE repository; {proj.path} holds {len(states)}"
    refusal = nodes.cloud_git_refusal(states[0])
    if refusal:
        return refusal
    base_dir = _expand_base_dir(config.base_dir) if config.base_dir else None
    project_dir = Path(_resolve_path(proj.path, base_dir) or proj.path)
    ps = nodes.cloud_push_set(
        project_dir, states, home=Path.home(), extras=proj.push or ()
    )
    return nodes.cloud_env_refusal(
        sid, nodes.project_name(proj), ps, nodes.read_recipient()
    )

    3.20.0 and magent never writes a cloud session's MCP config, so the gap
    is named whenever ``settings.mcpRelay`` asks for a relay at all."""
    return CLOUD_UNREACHABLE if config.settings.mcp_relay else None
```

```python
def bring_up(
    config: MagentConfig,
    only: list[str] | None = None,
    group: str | None = None,
    *,
    refusals: dict[str, str] | None = None,
) -> tuple[list[str], list[str]]:
    """Create detached psmux sessions for eligible projects.

    ``only`` restricts creation to the given session names; ``group`` to one
    project group. Returns ``(created, failed)``: the sessions the creation
    verify PROVED are up, and the ones still missing after
    ``launch_verified``'s one respawn, plus every cloud create
    ``launch.cloud_refusal`` refused (spec §18.4). A refused create's reason
    lands in ``refusals``, keyed by session id, when the caller passes one. A
    cloud pane is typed once (``resend=False``) and branded ``@cloud``."""
    # in-body: psmux is a leaf (its module level imports only magent.log), and
    # launch is a heavy subsystem that itself imports psmux only in-body. By
    # call time both modules are loaded, so this is not an import cycle.
    from magent import launch
    from magent.platform import get_platform

    plat = get_platform()
    windows: list[PsmuxWindowOpts] = []
    refused: list[str] = []
    for p in eligible_projects(config, group):
        sid = _field_str(p, "session")
        if only is not None and sid not in only:
            continue
        if not p["resolved"] or not p["cmd"]:
            continue
        cloud = p.get("node") == "cloud"
        if cloud and not has_session(sid):
            reason = launch.cloud_refusal(config, sid)
            if reason:
                get_logger("launch").warning(
                    "cloud session %s not created: %s", sid, reason
                )
                refused.append(sid)
                if refusals is not None:
                    refusals[sid] = reason
                continue
        windows.append(
            PsmuxWindowOpts(
                window_name=sid,
                cwd=_field_str(p, "resolved"),
                command=_field_str(p, "cmd"),
                resend=not cloud,
                nick="cloud" if cloud else None,
            )
        )
    names = [w.window_name for w in windows]
    if not windows:
        return [], refused
    failed = launch_verified(plat, windows)
    stuck = set(failed)
    return [n for n in names if n not in stuck], [*failed, *refused]
```

```python
def _push_cloud(
    cfg: MagentConfig, proj: ProjectConfig, name: str, *, yes: bool
) -> None:
    """Spec §18.11c: hand the push set off by hand. The record it writes is
    what opens the create gate. J11s puts sealing in front of the hand-off,
    if J0-B lets phase 2 be built (DECISION-18)."""
    from magent import launch  # heavy subsystem: in-body per policy

    sid = nodes.node_sid(proj)
    states = launch.node_git_states(cfg, proj)
    if len(states) != 1:
        _fail(
            f"a cloud session runs ONE git repository; {proj.path} holds {len(states)}",
            _EXIT_USAGE,
        )
    state = states[0]
    git_refusal = nodes.cloud_git_refusal(state)
    if git_refusal:
        _note(f"the cloud create is also blocked: {git_refusal}")
    project_dir = _local_dir(cfg, proj)
    if project_dir is None:
        _fail(f"{proj.path} does not exist on this machine", _EXIT_USAGE)
    ps = nodes.cloud_push_set(
        project_dir, states, home=Path.home(), extras=proj.push or ()
    )
    for path in ps.outside:
        _note(f"{path} is outside the project: no path reaches a cloud session")
    if not ps.files:
        nodes.write_cloud_record(
            sid, digest=nodes.push_set_digest(ps, "manual"), mode="manual"
        )
        _ok(f"{name}: nothing inside the project to hand off")
        return
    _manual_handoff(ps, sid, name, yes=yes)


def _manual_handoff(ps: nodes.CloudPushSet, sid: str, name: str, *, yes: bool) -> None:
    """Spec §18.11c: names masked on screen, the values in a private temp file."""
    click.echo(f"\n  {style(f'{name} -> cloud, by hand', bold=True)}")
    for line in nodes.masked_lines(ps):
        click.echo(f"    {line}")
    handoff = nodes.write_manual_handoff(ps) if ps.env_files else None
    if handoff is not None:
        click.echo(
            f"\n  Paste the contents of\n    {handoff}\n"
            "  into claude.ai/code > environment settings > Environment variables.\n"
            "  Use a PERSONAL environment: anyone who uses the environment can read the values."
        )
    for path in ps.files:
        if path not in ps.env_files:
            _note(
                f"{ps.rel(path)} cannot travel by hand: only .env text can be pasted into an environment"
            )
    if yes:
        if handoff is not None:
            _note(f"delete {handoff} once it is pasted")
    else:
        confirmed = click.confirm(
            "\n  Done -- let magent create the cloud session?", default=False
        )
        if handoff is not None:
            handoff.unlink(missing_ok=True)
        if not confirmed:
            _fail("not confirmed; nothing recorded", _EXIT_USAGE)
    nodes.write_cloud_record(
        sid, digest=nodes.push_set_digest(ps, "manual"), mode="manual"
    )
    _ok(f"recorded; magent up {name} will create the cloud session")
```

```python
def _why_manual(manual: bool, url: str) -> str | None:
    """Why this push cannot be sealed, or None (spec §18.11). Unknown
    visibility counts as public: ciphertext in a public repo is published."""
    from magent import remote_mux  # heavy subsystem: in-body per policy

    if manual:
        return "--manual"
    if nodes.read_recipient() is None:
        return "no sealing key yet (run magent node cloud-setup)"
    if remote_mux.find_age() is None:
        return "age is not on PATH (winget install FiloSottile.age)"
    private = remote_mux.repo_is_private(url)
    if private is False:
        return "the repository is public"
    if private is None:
        return "could not confirm the repository is private (is gh signed in?)"
    return None


def _push_cloud(
    cfg: MagentConfig, proj: ProjectConfig, name: str, *, manual: bool, yes: bool
) -> None:
    """Spec §18.11: seal the push set into the project's GitHub repo, or hand
    it off by hand. Either way the record is what opens the create gate."""
    from magent import launch, remote_mux  # heavy subsystem: in-body per policy

    sid = nodes.node_sid(proj)
    states = launch.node_git_states(cfg, proj)
    if len(states) != 1:
        _fail(
            f"a cloud session runs ONE git repository; {proj.path} holds {len(states)}",
            _EXIT_USAGE,
        )
    state = states[0]
    git_refusal = nodes.cloud_git_refusal(state)
    if git_refusal:
        _note(f"the cloud create is also blocked: {git_refusal}")
    project_dir = _local_dir(cfg, proj)
    if project_dir is None:
        _fail(f"{proj.path} does not exist on this machine", _EXIT_USAGE)
    ps = nodes.cloud_push_set(
        project_dir, states, home=Path.home(), extras=proj.push or ()
    )
    for path in ps.outside:
        _note(f"{path} is outside the project: no path reaches a cloud session")
    if not ps.files:
        nodes.write_cloud_record(
            sid, digest=nodes.push_set_digest(ps, "manual"), mode="manual"
        )
        _ok(f"{name}: nothing inside the project to hand off")
        return
    why = _why_manual(manual, state.url)
    recipient = nodes.read_recipient()
    age_exe = remote_mux.find_age()
    if why is None and recipient is not None and age_exe is not None:
        try:
            ciphertext = remote_mux.seal(ps, recipient, age_exe=age_exe)
            commit = remote_mux.publish_sealed(
                state.path, state.url, ciphertext, label=name
            )
        except remote_mux.SealError as exc:
            _fail(
                f"sealing failed ({exc}); nothing recorded. magent node push {name} --manual hands it off by hand",
                1,
            )
        nodes.write_cloud_record(
            sid,
            digest=nodes.push_set_digest(ps, recipient),
            mode=recipient,
            commit=commit,
        )
        _ok(
            f"{name}: sealed {len(ps.files)} file(s) to {cloud_plugin.SEALED_REF} ({commit[:12]}); "
            "the magent-cloud plugin restores them at session start"
        )
        return
    _note(f"handing off by hand: {why}")
    _manual_handoff(ps, sid, name, yes=yes)
```
