# Nodes Sub-plan I: the real-wire `needs_ssh` tier (`tests/e2e/test_nodes_real.py`)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prove the nodes feature over a real wire. The CI runner acts as its own node, nick `loop`, reached through the existing loopback sshd. A real `git clone` runs from a local bare repo, and a real `tmux -L magent` session hosts a stand-in agent. The tier then covers real transcript pulls, a real `magent-attach-client --mux tmux` redial, `down` and `recall`.

**Architecture:** There is one new test module and one new stdlib stand-in, `tests/e2e/_node_agent.py`. The module is marked `e2e` and `needs_ssh` but not `real_home`. The PC side runs `python -m magent` children under an explicit tmp HOME. The node side is whatever sshd hands the remote command, which is the runner's passwd home, so every test that hosts a session is gated CI-only and restores that home byte for byte. One module-scoped bring-up is shared by every node-hosting test, and one `_pty.Budget` bounds the whole module. Linux runs everything. macOS and Windows run only the client-side legs, and the node half announces its absence with a `::warning`.

**Tech Stack:** pytest, stdlib only, reusing the helpers in `tests/e2e/test_ssh_real.py` and `tests/e2e/_pty.py`. It also uses real `ssh`, `git`, `tmux` and `bash` on the Linux runner. There are no new dependencies and no CI or provisioning changes. `.github/actions/setup-ssh-server` and the `End-to-End` job already install tmux and run `-m "e2e and needs_ssh"`.

## Decisions (read before Task 1)

**No `real_home` marker.**
- The PC side never needs the real home. Every product process runs as a `python -m magent --config <cfg>` child whose env points the whole HOME family (`HOME`/`USERPROFILE`/`HOMEDRIVE`/`HOMEPATH`) at `<base>/h`. This is the same device as `test_fleet_real.py`, and conftest's guard B has nothing to object to.
- The in-process calls (`remote_mux.has_session`, `remote_mux.run`) run under conftest's normal per-test redirect.
- ssh still finds the `mdssh` alias. OpenSSH on Linux and macOS resolves `~/.ssh` from the passwd entry, not `$HOME`. The `_ssh` helper fails loudly naming this assumption if it is ever wrong.
- The node side cannot be redirected by any means. sshd starts the remote command with the passwd home, and neither `--config` nor an env var reaches past it.
- So everything the node writes lands in the runner's real home, which is exactly what a real node does. That covers provision's `~/.claude/settings.json` hooks, `~/.claude.json`, the state hook, gh config, the stand-in's transcript and the memory push.
- The tier handles that with the posture `test_ssh_real.py` already uses:
  - every node-hosting test is gated by `_require_real_home_ok()`, so it runs only when `GITHUB_ACTIONS=true` or `MDTEST_ALLOW_REAL_HOME=1`;
  - `_HomeMemo` captures `~/.claude`, `~/.claude.json`, `~/.magent` and `~/.config/gh` byte for byte before the bring-up and restores them after.
- The node root and the PC home both live under one short `mkdtemp(prefix="mgn-", dir="/tmp")` directory, as the lead asked.
- Two homes, one on each side of the wire, is also what makes the loopback a faithful two-machine model. `HOME` inside the pane must equal the node home and never the PC home, and a test asserts it.

**Linux runs the node half; macOS and Windows run the client half.**
- A node is a Linux box: `bring_up.sh`/`pull.sh` rely on tmux, GNU `tar --newer-mtime` and bash ≥ 4.
- macOS's sshd is best-effort in CI and ships bsdtar and bash 3.2. Windows's sshd shell is cmd.exe with no tmux.
- The node-hosting tests therefore skip off Linux, and one dedicated test emits the `::warning` once per non-Linux leg, like `TestRemoteWindowLegMacos`.
- The client half runs on every OS:
  - the unreachable-node probe answers None;
  - the D7 refusal;
  - `--go --dry-run` touches nothing;
  - the product's ssh argv round-trips a command. This one is Linux and macOS only; see the note on that test.

**`magent up`, not `--go`, drives the real bring-up.**
- `--go` ends in `attach_client.spawn_attach_window`, which is a `wt` window, Windows-only by design (PR-C).
- `up` is the same bring-up (spec §7 heading "`--go`, menu, `magent up`") without the window.
- `--go` is still exercised where it stops before any window: the refusal and `--dry-run` legs, on every OS.

**Stand-in: a new `tests/e2e/_node_agent.py`, not `_fleet_agent.py`.**
- `_fleet_agent.py` imitates Claude Code's *screen* (the `❯` line and footer). Nothing on the node path reads the screen.
- The node path reads the *transcript file*, the *process environment* and the *cwd*, and `_fleet_agent.py` produces none of them.
- The new stand-in is a small stdlib script with four jobs:
  - it dumps `{cwd, env}`;
  - it appends JSONL records to `~/.claude/projects/<encode_claude_project_path(cwd)>/<session-id>.jsonl`. It imports the product's ONE encoder (DECISION-11a/f) rather than restating the rule; a restated regex already drifted once, by keeping `_`;
  - it records one more turn each time a poke file changes, so a test controls exactly when the transcript's mtime moves;
  - it exits by itself after `--max-seconds`.

**Test-law exception, stated once.** Master §0 says tests never resolve the real `ssh`/`tmux`/`git`-that-writes. That is the unit-tier law. Spec §16 names this tier as the one place those binaries are real, on a CI runner only.

**Cleanup.**
- Teardown kills only the `tmux -L magent` sessions this module named, never `kill-server`, and verifies each is gone.
- It kills only ssh clients whose command line carries this module's sid.
- It restores the node home memo and rmtrees the short base dir.

**Budget.** `NODES_BUDGET_S = 300`.
- The healthy path is about 75–110 s: one clone, one re-up fetch, five pulls, one redial and one recall.
- `test_nodes_real.py` sorts before `test_ssh_real.py`, so it runs first in the `needs_ssh` step and still leaves that tier its share of the 20-minute job.
- Every subprocess timeout is `max(5, budget.clamp(want))`.

**Red/green in this tier.** Tasks 2–12 write tests against behaviour B–G already shipped. Their locally observable result is SKIPPED, because the `MDTEST_SSH_*` variables are absent everywhere except CI. The real red/green happens on CI. Each task therefore verifies three things locally:
- the module still collects;
- the stand-in test (Task 1) and the child-env pin test (Task 2) still pass;
- the fast gate is green.

Task 1 is the one real local red→green.

**When CI actually runs it.**
- `ci.yml` runs on pushes and PRs to `main` only, so PRs based on `feat/nodes` will not run this tier.
- The first real run is the `feat/nodes → main` PR, unless the orchestrator opens a draft PR to `main` earlier purely for CI signal. That is the orchestrator's call, not this sub-plan's.

```python
"""REAL node tier: a project's session runs on a "node" that is this runner.

The nodes feature moves a project's agent onto a pool machine: git is the
truth (the node holds a clone), the session lives in ``tmux -L magent`` there,
transcripts come home by pull, and the local window is the existing attach
supervisor speaking ``--mux tmux``. The unit tier pins every argv through the
fake ssh; this file drives the REAL thing through the CI loopback sshd
(``.github/actions/setup-ssh-server``), with the runner as its own node --
nick ``loop``, the runner user, a fresh short root under ``/tmp``:

* the stand-in agent's own contract (runs anywhere, no wire);
* ``remote_mux.has_session``'s tri-state over a real client: unreachable is
  None (every OS), absent is False and a real tmux session is True (Linux);
* the D7 refusal and ``--go --dry-run`` touching nothing (every OS);
* ONE real ``magent up`` (Linux): clone at the local HEAD, a live session on
  the magent socket, the node brand on the status bar, the push set (the
  gitignored ``.env`` byte-identical at 0600, the auto-memory, nothing else),
  and no environment from the PC crossing into the pane;
* ``magent node sync --once`` pulling the transcript home byte-identical, and
  re-pulling only a file the node changed;
* ``magent-attach-client --mux tmux`` redialling a killed connection back into
  the same session;
* ``magent down`` pulling the last turn and killing the session, and
  ``magent node recall --local`` handing it back with the exact resume line.

Homes: the PC side is always a child process under an explicit tmp HOME. The
node side is whatever sshd gives the remote command -- the runner's REAL
passwd home -- so every node-hosting test is gated CI-only
(``_require_real_home_ok``) and ``_HomeMemo`` restores that home byte for byte.
Linux runs everything; macOS and Windows run the client half and say so with
a ``::warning``. One ``_pty.Budget`` bounds the module; teardown kills only
the tmux sessions and ssh clients this module named.
"""

from __future__ import annotations

import json
import os
import subprocess
import sys
from pathlib import Path

import pytest

pytestmark = [pytest.mark.e2e, pytest.mark.needs_ssh]

READY = "NODE-READY"  # tests/e2e/_node_agent.py prints exactly this
_AGENT = Path(__file__).with_name("_node_agent.py")


class TestTheStandInAgent:
    """The stand-in is test infrastructure, so it gets a test of its own: if it
    wrote its transcript anywhere but where the product looks, every pull test
    below would fail for a reason that is not the product's."""

    def test_the_stand_in_writes_its_transcript_where_claude_code_would(
        self, tmp_path
    ):
        from magent.sessions.claude import encode_claude_project_path

        home = tmp_path / "h"
        home.mkdir()
        # A space, an underscore and a dot: every unit outside [A-Za-z0-9]
        # becomes '-' (DECISION-11a). The underscore is the one a restated
        # regex once got wrong; tmp_path's own name carries more of them.
        work = tmp_path / "w d_x.y"
        work.mkdir()
        poke = tmp_path / "poke"
        poke.write_text("qwerty", encoding="utf-8")
        env_out = tmp_path / "env.json"
        drive, tail = os.path.splitdrive(str(home))
        env = {
            k: v for k, v in os.environ.items() if not k.upper().startswith("MAGENT_")
        }
        env.update(HOME=str(home), USERPROFILE=str(home), HOMEDRIVE=drive, HOMEPATH=tail)

        proc = subprocess.run(
            [
                sys.executable,
                str(_AGENT),
                "--session-id",
                "sid-123",
                "--env-out",
                str(env_out),
                "--poke",
                str(poke),
                "--max-seconds",
                "1.5",
            ],
            cwd=str(work),
            env=env,
            capture_output=True,
            text=True,
            timeout=60,
            check=False,
        )

        assert proc.returncode == 0, proc.stderr
        assert READY in proc.stdout, proc.stdout
        assert "MARK-qwerty" in proc.stdout, proc.stdout
        dump = json.loads(env_out.read_text(encoding="utf-8"))
        assert os.path.samefile(dump["cwd"], work)
        encoded = encode_claude_project_path(dump["cwd"])
        assert "_" not in encoded and "w-d-x-y" in encoded, encoded
        transcript = home / ".claude" / "projects" / encoded / "sid-123.jsonl"
        records = [
            json.loads(line)
            for line in transcript.read_text(encoding="utf-8").splitlines()
        ]
        assert [r["type"] for r in records] == ["start", "poke"]
        assert records[1]["text"] == "qwerty"
```

```python
"""Stand-in for Claude Code on a node, for tests/e2e/test_nodes_real.py.

Not a test module (no ``test_`` prefix). It runs INSIDE a real
``tmux -L magent`` session on the loopback "node" and imitates the three
things the nodes feature reads from a real agent:

* where it runs -- it dumps ``{"cwd", "env"}`` to ``--env-out`` at start, the
  ground truth for "the pane runs in the remote dir", ``LANG=C.UTF-8``, "HOME
  is the node's", and "no environment from the PC crossed";
* its transcript -- JSONL records appended to
  ``~/.claude/projects/<encode_claude_project_path(cwd)>/<session-id>.jsonl``,
  the path Claude Code uses. The encoder is the product's ONE encoder
  (DECISION-11a/f), imported, never restated: Claude Code's rule is fixed by
  Claude Code, and B's vectors pin magent's copy of it;
* a turn on demand -- each time the ``--poke`` file's content changes it
  appends one record and prints ``MARK-<content>``, so a test decides exactly
  when the transcript's mtime moves (the pull-watermark test depends on it).

It prints ``NODE-READY`` once its first record is on disk. Needles carry no
spaces and no doubled characters: tmux redraws a reattached pane with cursor
motion and may encode a run of one character as REP, either of which splits a
needle that has them. Stdlib plus magent's encoder: the pane runs it with the
venv's own interpreter, whose editable install resolves ``magent`` whatever the
pane's login environment is. It exits by itself after ``--max-seconds`` so a
lost teardown cannot leave it running for the rest of the job.
"""

from __future__ import annotations

import argparse
import json
import os
import sys
import time
from pathlib import Path

from magent.sessions.claude import encode_claude_project_path

READY = "NODE-READY"
POLL_S = 0.2


def _say(line: str) -> None:
    sys.stdout.write(line + "\n")
    sys.stdout.flush()


def main(argv: list[str] | None = None) -> int:
    ap = argparse.ArgumentParser(prog="_node_agent")
    ap.add_argument("--session-id", required=True)
    ap.add_argument("--env-out", required=True)
    ap.add_argument("--poke", required=True)
    ap.add_argument("--max-seconds", type=float, default=600.0)
    opts = ap.parse_args(argv)

    cwd = os.getcwd()
    Path(opts.env_out).write_text(
        json.dumps({"cwd": cwd, "env": dict(os.environ)}, sort_keys=True),
        encoding="utf-8",
    )
    tdir = Path.home() / ".claude" / "projects" / encode_claude_project_path(cwd)
    tdir.mkdir(parents=True, exist_ok=True)
    transcript = tdir / f"{opts.session_id}.jsonl"

    def record(kind: str, text: str) -> None:
        line = json.dumps(
            {
                "type": kind,
                "sessionId": opts.session_id,
                "cwd": cwd,
                "text": text,
                "ts": time.time(),
            }
        )
        with transcript.open("a", encoding="utf-8", newline="\n") as fh:
            fh.write(line + "\n")

    record("start", READY)
    _say(READY)

    poke = Path(opts.poke)
    seen = ""
    deadline = time.monotonic() + opts.max_seconds
    while time.monotonic() < deadline:
        try:
            value = poke.read_text(encoding="utf-8").strip()
        except OSError:
            value = ""
        if value and value != seen:
            seen = value
            record("poke", value)
            _say(f"MARK-{value}")
        time.sleep(POLL_S)
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

```python
    """The home sshd gives the node user's remote commands: the passwd entry,
    which no HOME redirect reaches."""
    import pwd

    return Path(pwd.getpwuid(os.getuid()).pw_dir)


def _node_home_roots() -> tuple[Path, ...]:
    home = _node_home()
    return (
        home / ".claude",
        home / ".claude.json",
        home / ".magent",
        home / ".config" / "gh",
    )


def _read(path: Path) -> str:
    try:
        return path.read_text(encoding="utf-8", errors="replace")
    except OSError:
        return ""


@dataclass
class _HomeMemo:
    """Byte-for-byte memo of the node user's REAL-home paths a bring-up writes.

    Provision (settings.json hooks, ~/.claude.json, the state hook, gh), the
    stand-in's transcript and the memory push all land in the runner's real
    home, because that is where a node keeps them. Captured before the
    bring-up, restored after: files that appeared are deleted, files that
    changed get their bytes and mode back, directories that appeared are
    removed, symlinks are left exactly as found."""

    roots: tuple[Path, ...]
    files: dict[Path, tuple[bytes, int]] = field(default_factory=dict)
    dirs: set[Path] = field(default_factory=set)
    links: set[Path] = field(default_factory=set)

    @staticmethod
    def _walk(root: Path) -> list[Path]:
        if root.is_dir() and not root.is_symlink():
            return [root, *root.rglob("*")]
        return [root]

    @classmethod
    def capture(cls, roots: tuple[Path, ...]) -> _HomeMemo:
        memo = cls(roots)
        for root in roots:
            for path in cls._walk(root):
                if path.is_symlink():
                    memo.links.add(path)
                elif path.is_dir():
                    memo.dirs.add(path)
                elif path.is_file():
                    memo.files[path] = (path.read_bytes(), path.stat().st_mode)
        return memo

    def restore(self) -> None:
        for root in self.roots:
            deepest_first = sorted(
                self._walk(root), key=lambda p: len(p.parts), reverse=True
            )
            for path in deepest_first:
                if path.is_symlink():
                    if path not in self.links:
                        path.unlink()
                elif path.is_dir():
                    if path not in self.dirs:
                        shutil.rmtree(path, ignore_errors=True)
                elif path.exists() and path not in self.files:
                    path.unlink()
        for path, (data, mode) in self.files.items():
            path.parent.mkdir(parents=True, exist_ok=True)
            if not path.is_file() or path.read_bytes() != data:
                path.write_bytes(data)
            path.chmod(stat.S_IMODE(mode))
```

```python
    reup: tuple[int, str, str]
    ready: bool
    killed: tuple[int, str, str]
    placed: bool
    recall: tuple[int, str, str]

    def require_arranged(self) -> None:
        rc, out, err = self.reup
        assert rc == 0 and self.ready, (
            f"the re-up before the recall failed (rc={rc}, agent ready="
            f"{self.ready})\n--- stdout ---\n{out}\n--- stderr ---\n{err}"
        )

        assert self.placed, "the re-up recorded no placement to recall from"


@pytest.fixture(scope="module")
def recalled(rig: _Rig, downed: _Downed) -> _Recalled:
    """``magent node recall <name> --local`` on a KILLED session whose
    placement is still recorded (R-G1).

    G's recall reads the node map and never falls back to the pin. After
    ``down`` the entry is gone and recall refuses, by design, with "nothing
    to recall". So the project is brought up once more with the same verb
    (the clone exists, so it is a fetch), and its session is killed
    OUT-OF-BAND with a raw tmux kill. That stands in for a crash, an OOM or a
    reboot, anything but a magent verb, so the placement survives. Recall
    then has a dead session, a live placement and a transcript on the node's

            timeout=_t(rig.budget, 60),
            interval=0.25,

        "node", "recall", rig.name, "--local", tag="recall", timeout=150
    )

        reup=reup, ready=ready, killed=killed, placed=placed, recall=recall
```
